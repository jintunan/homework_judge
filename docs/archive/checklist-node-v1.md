## 参考答案自动配置

- [x] AC2：上传模板与参考答案后，系统生成包含题号、题干、题型、满分、答案和评分点的逐题草稿。（验证：使用包含三种题型的受控试卷）
- [x] 试卷与参考答案的原始视觉模型响应、解析结果和 Token 用量可查看且只读。（验证：打开运行历史并与数据库记录对照）
- [x] AC6：参考答案缺题时只标记相应题目异常，不把其他答案强行匹配到该题。（验证：使用故意缺少一题的答案文件）
- [x] AC6：题号无法对应、题型不支持和低置信度结果均显示“需人工处理”。（验证：用固定模型输出逐一触发）
- [x] 初中数学简单简答题草稿包含关键步骤和分步分值。（验证：检查受控数学题的评分点）
- [x] AC7：高中物理计算题草稿包含关键公式、代入过程、单位要求和分步分值。（验证：检查受控物理题的评分点）

## 联网搜索与模型回退

- [x] AC3：无参考答案模式先识别整卷题目，再为每道题创建独立联网搜索运行。（验证：检查运行时间顺序和调用记录）
- [x] AC4：搜索成功时答案来源标为“联网检索”，并显示来源标题、HTTP(S) URL、有限长度摘要和检索时间。（验证：使用假百炼搜索成功响应）
- [x] 搜索来源按返回顺序保存，刷新页面后链接和摘要保持不变。（验证：返回三个固定来源并逐项对照）
- [x] 没有 `search_info`、没有来源、没有直接答案或置信度不足时不能标记为“联网检索”。（验证：分别构造四类响应）
- [x] AC5：搜索无法得到可靠答案时自动调用模型生成，来源标为“模型生成”。（验证：假搜索返回 `not_found`，断言生成器被调用一次）
- [x] AC5：模型生成草稿保存答案、评分点、简要依据、置信度和原始响应。（验证：查看答案卡和运行历史）
- [x] 搜索请求异常与“未找到答案”可区分，异常原因对教师可见。（验证：分别返回 429、超时和正常空结果）
- [x] 搜索失败且模型生成也失败时，仅该题标记失败，其他题继续完成。（验证：五题任务中固定一题双重失败）
- [x] 搜索和模型生成实际并发不超过 `ANSWER_CONFIG_CONCURRENCY`。（验证：假服务记录峰值并发）
- [x] 限流和可恢复服务错误只执行有限重试，不形成无限调用。（验证：持续返回 429 并检查总调用次数）

- [x] AC8：教师修改后仍能查看原始自动答案、来源、置信度和模型响应。（验证：修改前后对照运行历史）
- [x] 负分、空答案、重复题号、不支持题型和评分点总分超限不能审核通过。（验证：逐项提交非法数据）
- [x] AC9：教师可审核通过和退回单题，退回原因持久化。（验证：完成通过与退回并刷新）
- [x] AC9：重新搜索只处理所选题目，不重新识别整卷或影响其他题目。（验证：比较所有题目的运行数）
- [x] AC9：直接重新生成跳过搜索，并为所选题目新增模型生成运行。（验证：检查假服务调用顺序）

## 端到端场景

- [x] 场景 1——参考答案：创建初中数学任务 → 上传试卷和参考答案 → 自动提取 → 教师修改并逐题通过 → 发布 → 批改学生试卷 → 确认成绩 → 查看报告与统计。
- [x] 场景 2——联网命中：创建高中物理任务 → 不上传参考答案 → 识别题目 → 联网搜索得到带来源答案 → 教师审核发布 → 完成学生批改。
- [x] 场景 3——生成回退：搜索没有可靠来源 → 模型生成物理计算题答案与评分点 → 页面明确显示“模型生成” → 教师审核发布。
- [x] 场景 4——单题失败：一题搜索和生成失败 → 其他题正常进入待审核 → 教师对失败题重新搜索 → 成功后发布。
- [x] 场景 5——版本追溯：发布 V1 并批改学生 A → 修改答案生成 V2 → V2 审核期间阻止新上传 → 发布 V2 并批改学生 B → A、B 报告分别显示正确版本。
- [ ] 场景 6——真实百炼：使用脱敏数学试卷分别完成有参考答案与无参考答案流程。（验证：保存运行 ID、模型 ID、来源和教师审核结果）
- [ ] 场景 7——真实百炼：使用脱敏高中物理试卷完成无参考答案搜索及至少一道计算题配置。（验证：保存运行 ID、来源、评分点和教师审核结果）
