- 教师确认、修正选择题识别、逐空改判、逐评分点改判和原图拖框修改错误位置。
- 满分绿色勾、零分红圈、部分分橙色三角与分数、首个失分位置；待复核题不绘制最终标记。
- 多页批注试卷 PDF、真实学生作答裁剪图和错题分析 PDF；不展开完整答案或完整解题过程。
- 生成物修订、当前/过期状态、安全预览下载和只重建生成物。
- 批改工作台：进度、筛选、证据/批注图层、复核、原图拖框、预览和下载。
