# 题框变更后单题重新识别 Checklist

> 每项均通过运行自动化测试、检查持久化结果或观察界面行为进行验证，重点核对系统行为，
> 不以内部实现细节替代验收。

## 实现完整性

- [ ] 题框编辑器显示“保存并重新识别本题”，且与普通“保存题框修改”含义清楚区分。
  （验证：打开任意非重复题的题框编辑器，观察两个独立操作按钮）
- [ ] 没有未保存草稿时也能主动重新识别当前题。
  （验证：不调整已保存题框直接点击新按钮，观察产生一次当前题识别请求）
- [ ] 有未保存的新增、移动、缩放或删除片段时，新操作提交当前全部草稿并先保存题框。
  （验证：增加下一页片段后点击新按钮，检查请求片段和服务器题框均包含最新草稿）
- [ ] 普通“保存题框修改”仍只保存几何，不触发模型调用。
  （验证：点击普通保存并检查模型伪客户端调用次数保持为零）
- [ ] 单题识别使用当前题在所有模板页上的全部题框片段，并按页码和片段顺序输入模型。
  （验证：为同一题配置两个跨页片段，检查模型输入的片段标识、页码和顺序）
- [ ] 模型输入仅包含题框裁剪和必要上下文，不包含无关整页或整卷图像。
  （验证：检查模型伪客户端收到的图像尺寸和数量与题框裁剪一致）
- [ ] 单题模型输出必须恰好是一道题，零题、多题和非法结构均被拒绝。
  （验证：分别模拟三类返回，观察稳定错误且题目内容不变）
- [ ] 成功结果原地更新题号、题干、选项、题型、分值、来源页、置信度和识别问题。
  （验证：调用接口后读取当前题复核详情并与模型返回逐字段比较）
- [ ] 成功后当前题内容确认状态和题框项状态均为待确认。
  （验证：读取复核详情，观察两个状态均提示教师重新确认）
- [ ] 单题重新识别具有独立运行记录和审计事件。
  （验证：查询运行与审计数据，看到题目 ID、题框版本、模型、提示词版本、响应、用量和结果）

## 数据保持与失效处理

- [ ] 当前题 ID、排序和其他题目的全部识别内容保持不变。
  （验证：操作前后对比数据库与复核响应，只允许目标题模型字段变化）
- [ ] 已有关联的答案条目 ID 保持不变，且匹配进入待复核而不是自动换绑。
  （验证：操作前后对比匹配记录，并观察“原答案关联已保留”的待复核原因）
- [ ] 教师直接录入的标准答案和解析保持不变。
  （验证：先录入直接答案与解析，再重新识别并读取匹配详情）
- [ ] 已有教师题目内容覆盖不会被模型静默覆盖。
  （验证：先修改题干并保存教师覆盖，再重识别，界面仍显示教师内容）
- [ ] 保留教师覆盖时界面明确提示模型原始识别已更新、当前仍显示教师修改内容。
  （验证：执行上一场景并观察成功反馈）
- [ ] 有教师题号覆盖时规范化题号继续以教师题号为准；没有覆盖时使用新模型题号。
  （验证：分别执行有覆盖和无覆盖场景，检查规范化题号）
- [ ] 依赖旧题干的当前填空配置被标记为过期，历史配置仍可查询。
  （验证：为填空题建立已确认配置后重识别，检查当前就绪状态和历史版本）
- [ ] 已存在的学生处理与评分结果被标记为需要重新处理，历史记录不被删除。
  （验证：准备现有结果后重识别，检查当前指针/状态和历史行数量）
- [ ] 操作不会自动重新处理学生答卷或重新批改。
  （验证：检查学生处理与评分任务伪执行器调用次数为零）

## 并发与失败安全

- [ ] 旧题框修订号提交被拒绝，不覆盖当前题框或题目。
  （验证：先在另一请求更新题框，再提交旧修订重识别，观察版本冲突）
- [ ] 模型等待期间题框再次变化时，晚到识别结果被拒绝，不覆盖新题框对应的题目状态。
  （验证：用可控模型暂停请求、更新题框后释放模型，检查提交冲突和原题内容）
- [ ] 任务正在处理学生答卷时单题重新识别被阻止。
  （验证：设置学生处理状态为运行中，调用接口得到明确冲突且无模型调用）
- [ ] 评分任务正在运行时单题重新识别被阻止。
  （验证：设置活动评分状态，调用接口得到明确冲突且无模型调用）
- [ ] 模型超时或服务异常时，最新题框已经保存但原题内容完全保持原值。
  （验证：模拟模型抛错，对比操作前后题框和题目字段）
- [ ] 模型非法 JSON、零题或多题时，最新题框保留、原题内容不发生部分写入。
  （验证：逐一模拟异常输出并比较持久化值）
- [ ] 失败运行记录包含错误码、错误信息和结束时间，便于追踪。
  （验证：查询失败的 `single_question_recognition` 运行）
- [ ] 题框引用缺失模板页、原图尺寸不符或裁剪退化时，在模型调用前失败并说明原因。
  （验证：构造三类损坏输入，检查模型调用次数为零）
- [ ] 重复题不能执行单题重新识别。
  （验证：标记为重复题后直接调用接口，观察明确拒绝且数据不变）

## 界面行为

- [ ] 第 12 题切换到下一模板页后可以增加第二个题框片段并调整位置。
  （验证：在题框编辑器切页、增加片段并拖动，观察片段归属于下一页）
- [ ] 点击新按钮后显示“正在保存题框并重新识别…”，期间所有冲突的题框操作不可重复提交。
  （验证：用延迟请求观察按钮文字与禁用状态）
- [ ] 成功后题干编辑器显示刷新后的模型原始内容或保留的教师有效内容，来源页包含跨页页码。
  （验证：完成跨页识别后观察当前题复核界面）
- [ ] 成功后界面提示需要重新确认题目内容和题框。
  （验证：观察确认状态、题框状态和操作提示）
- [ ] 版本冲突提示教师刷新，不丢失仍可恢复的本地草稿。
  （验证：模拟 409 响应，观察错误提示和画布草稿）
- [ ] 模型失败信息以可理解中文显示，教师仍可继续调整或再次尝试。
  （验证：模拟模型错误，观察局部反馈并再次移动题框）
- [ ] 本地题框存在几何阻断问题时，新按钮不可用并显示具体问题。
  （验证：制造越界或冲突题框，观察按钮禁用和阻断列表）

## 端到端场景

- [ ] 场景 1——第 12 题跨页补全：初始第 12 题只含第一页题干；教师到下一页增加片段，
  点击“保存并重新识别本题”；系统保存两个页面的片段，只调用一次当前题模型，题干随后
  包含两页完整原题，来源页为两页，其他题和答案关联不变，题目与题框等待重新确认。
- [ ] 场景 2——已有教师修改：教师已手工修正第 12 题题干后增加跨页片段并重新识别；系统
  更新模型原始题目但界面继续显示教师修正版，并明确提示教师覆盖被保留。
- [ ] 场景 3——模型失败：教师新增下一页片段后模型超时；系统保留新增题框，旧题干不变，
  显示可重试错误，并记录失败运行。
- [ ] 场景 4——并发编辑：模型识别期间另一操作修改题框；晚到结果被拒绝，后修改的题框和
  当前题目不被覆盖，页面提示刷新后重试。
