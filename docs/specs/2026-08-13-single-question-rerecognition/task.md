## T1：定义请求与响应契约

**文件：** `backend/homework_judge/schemas.py`、`shared/contracts.ts`

**依赖：** 无

**步骤：**

1. 新增单题重新识别请求模型，包含非负期望修订号和至少一个题框片段。
2. 复用现有题框片段字段与唯一性校验，不接受重复标识或重复顺序。
3. 定义响应中的题目 ID、运行 ID、保存后的题框集、识别题目摘要和教师覆盖保留标志。

**验证：** 后端模型校验测试能拒绝空片段、越界片段和重复片段；前端类型检查通过。

## T2：增加专用单题视觉识别能力

**文件：** `backend/homework_judge/recognition/prompts.py`、
`backend/homework_judge/recognition/service.py`、
`backend/tests/unit/test_single_question_recognition.py`

**依赖：** T1

**步骤：**

1. 定义单题识别提示词版本，明确输入是同一道题的有序跨页裁剪，禁止解题、补写、拆题或
   输出多个题目。
2. 构建用户输入，逐个附加片段标识、真实页码、阅读顺序和裁剪图像。
3. 复用现有试卷题目解析与规范化逻辑，将来源页限制在输入片段页集合内。
4. 要求解析结果恰好包含一道有效题；零题、多题或非法 JSON 返回稳定业务错误。
5. 返回规范化题目、原始响应和模型用量。
6. 用伪模型客户端覆盖同页、多页、零题、多题、非法响应和来源页限制测试。

**验证：** 运行单题识别单元测试，确认跨页两个片段只得到一道包含两个来源页的题目，所有
异常分支返回预期错误码。

## T3：实现保存后裁剪与运行捕获

**文件：** `backend/homework_judge/review/question_rerecognition.py`

**依赖：** T1、T2

**步骤：**

1. 检查题目存在、未标记重复、属于指定题框集任务，且当前没有学生处理或评分任务运行。
2. 调用题框服务按期望修订保存当前题全部片段，获得实际当前题框集；兼容冻结题框派生新
   草稿版本。
3. 从保存后的题框集重新读取当前题有序片段、题框集修订、内容哈希和题框项修订。
4. 按模板页读取原图，校验数据库尺寸，将归一化坐标确定性转换为像素边界并裁剪为 JPEG
   字节；拒绝缺页、图像尺寸不符或退化裁剪。
5. 创建 `single_question_recognition` 运行记录，保存题目、题框版本、内容哈希、片段页码、
   顺序和坐标摘要，不把裁剪图像持久化。

**验证：** 用临时数据库和已知尺寸图片运行用例准备阶段，确认裁剪数量、尺寸、顺序和运行
请求摘要均与服务器保存后的题框一致。

## T4：实现版本安全的识别结果提交

**文件：** `backend/homework_judge/review/question_rerecognition.py`

**依赖：** T3

**步骤：**

1. 在数据库事务外调用单题识别服务；捕获业务错误和意外错误并完成失败运行记录。
2. 提交前再次确认任务当前题框集 ID、题框集修订、内容哈希和当前题框项修订均等于捕获值。
3. 原地更新当前题的模型字段、来源页、置信度、问题和 `source_run_id`；保留题目 ID、排序、
   教师覆盖和现有答案关系。
4. 根据教师题号覆盖或新模型题号正确更新规范化题号；题目内容与题框均保持待确认。
5. 保留现有答案条目关联以及教师直接答案/解析，只把匹配状态转为待复核并写明关联已保留。
6. 将当前填空配置标记过期，调用现有题目上下文失效逻辑使当前学生处理与评分结果失效，
   但不删除历史记录。
7. 成功完成运行记录的原始响应、用量和结束时间，并写入单题重新识别审计事件。
8. 返回保存后的当前题框集、识别摘要和教师覆盖保留标志。

**验证：** 集成测试确认成功原地更新；教师覆盖、答案关联和直接答案不变；模拟模型等待期间
再次修改题框后，晚到结果返回冲突且题目不变。
