# 题框变更后单题重新识别 Spec

## 背景

试卷题目可能跨页。当前初次识别遗漏下一页内容时，教师可以为该题增加跨页题框片段，
但“保存题框修改”只更新题框几何，不会根据新范围重新识别题目原文。因此新增片段无法
补回第 12 题等跨页题目的后半段内容。

## 目标

- 教师调整或增加题框片段后，可以主动只重新识别当前题。
- 重新识别同时使用当前题在所有页面上的全部题框片段，按页码和片段顺序还原跨页原题。
- 不重跑整份试卷，不重建题目，不影响其他题目及当前答案关联。
- 识别结果继续进入现有教师复核流程，由教师确认后生效于后续处理。

## 功能需求

- F1：题框编辑器提供“保存并重新识别本题”操作；存在未保存的新增、移动、缩放或删除
  片段时，该操作先保存题框，再使用服务器保存后的题框识别。
- F2：单题识别必须读取当前题的全部题框片段，允许片段分布在多个模板页，并按页码、
  片段顺序提交给视觉模型。
- F3：模型只识别题框内属于当前题的完整原题，包括题号、题干、选项、题型和分值；
  跨页片段应合并为一道题，不能生成新题或改动相邻题。
- F4：识别成功后原地更新当前题的模型识别字段、来源页、置信度和识别问题；题目 ID、
  排序、答案条目关联、教师直接录入的标准答案和解析保持不变。
- F5：重新识别后，当前题的内容确认状态与题框确认状态均回到待确认；教师须重新核对
  题目内容和题框。
- F6：若当前题已有教师手工题目内容覆盖，系统保留该覆盖，不静默覆盖教师编辑；同时
  保存新的模型原始识别结果，供教师通过现有编辑界面对照或继续修改。
- F7：若题框无效、版本冲突、任务正处理学生答卷、模型失败或返回的不是唯一一道题，
  操作失败并显示明确原因；原题内容不得被部分写入。
- F8：单题重新识别应记录独立运行记录和审计事件，包括题目、题框版本、模型、提示词
  版本、原始返回和用量。

## 非功能需求

- N1：题框保存和识别结果写入必须避免半完成状态；识别失败时允许保留已经明确保存的
  题框修改，但原题识别内容保持原值。
- N2：重复点击、并发编辑或旧页面提交不得覆盖更新后的题框或题目内容。
- N3：发送给模型的图像只包含该题题框裁剪及必要的页码、顺序上下文，不发送无关整卷。
- N4：不依赖真实外部模型即可通过模拟返回完成后端和界面自动化测试。
- N5：现有整卷识别、题框保存/确认、答案匹配和其他题目复核行为保持兼容。

## 不做的事情

- 不在增加片段或普通保存时自动调用模型。
- 不重新识别整份试卷，也不删除或新建题目。
- 不根据单题重新识别结果自动改写标准答案、解析、评分细则或填空逐空配置。
- 不自动确认重新识别后的题目或题框。
- 不自动重新处理、识别或批改已经上传的学生答卷。
- 不在本轮新增识别模型、提示词或裁剪参数设置界面。

## 验收标准

- AC1：第 12 题原先只识别第一页内容时，教师在下一页增加并调整题框，点击“保存并重新
  识别本题”后，题干包含两个页面上的完整原题内容。
- AC2：操作包含未保存题框草稿时，服务器先保存正确的跨页片段，再基于这些片段识别，
  不使用旧题框。
- AC3：单题重新识别只产生当前题的识别运行；其他题目的内容、题目 ID 和确认状态不变。
- AC4：当前题的答案关联、教师直接录入答案和解析在重新识别后保持不变。
- AC5：识别成功后当前题内容和题框显示为待确认，教师可以检查、修改并重新确认。
- AC6：当前题已有教师手工内容覆盖时，重新识别不会覆盖该内容，并能明确提示模型原始
  识别已更新但教师覆盖仍被保留。
- AC7：模型超时、格式错误、返回零题或多题时，页面显示可理解的错误，原题内容保持不变。
- AC8：题框版本已被其他操作更新时，旧页面的重新识别请求被拒绝并提示刷新，不覆盖
  新题框。
- AC9：任务正处理学生答卷时，单题重新识别被阻止，不产生不一致的学生处理结果。
- AC10：运行记录可查到当前题、所用全部题框片段、模型、提示词版本、原始响应与用量。
- AC11：普通“保存题框修改”仍只保存题框，不触发模型调用。
- AC12：现有题目复核、题框 API、整卷识别和前端自动化测试继续通过。
