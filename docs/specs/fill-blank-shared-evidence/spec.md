# 多填空共享证据与教师审核优先 Spec

> **已被部分取代（2026-08-09）：** 本文中“按答案文本子串自动复制证据”“以题目级区域补齐缺失空位证据”的规则，已由 [题框驱动的逐空识别与模型批改 Spec](../2026-08-09-question-frame-blank-grading-pipeline/spec.md) 取代。共享证据仍被支持，但关系必须由无答案泄漏的键控识别显式返回并通过 evidence ID 校验，不能用标准答案或学生答案反向猜测。

## 背景

学生在同一处连续填写多个填空答案时，识别系统可能只产生一个包含全部答案的区域。当前系统会把该区域只关联给第一个空位，导致其余空位虽然已经识别并判定正确，却因缺少证据关联而无法通过教师复核。

当前第 9 题即属于该场景：同一区域识别出“失去、异种、吸引”，但证据只关联到 B1，B2、B3 的证据为空。

共享证据规则上线后，仍可能出现机器无法可靠补齐证据或错误位置的情况。此时教师已经查看原卷并明确确认或改判，系统却继续以“评分矛盾”阻止提交；即使复核项被关闭，错题报告生成也可能因为缺少错误位置而失败。这与“教师审核为最终判定”的业务原则不一致。

## 目标

- 在一个识别区域包含多个填空答案时，为匹配成功的空位共享该区域证据。
- 修复当前已有批改运行，无需重新识别或重新评分。
- 保持教师审核为最终判定，不让自动证据分配覆盖教师选择。
- 教师明确确认或改判后，所有评分审计告警只记录、不拦截，以教师确认的最终结果为准。
- 教师确认后正常完成剩余复核并生成错题报告；没有可靠位置时不伪造证据或红圈。

## 功能需求

- F1：当填空位没有独立证据区域时，系统检查题目级识别区域的文字是否包含该空位的实际作答。
- F2：内容匹配成功时，同一识别区域可以同时关联给多个空位，包括 B1、B2、B3 等。
- F3：内容匹配应忽略不影响答案含义的空白、换行和常见分隔符，但不得使用模糊语义猜测。
- F4：空答案、无法确认内容匹配或没有可用区域时，不自动共享证据。
- F5：自动共享仅补齐证据为空的空位，不替换空位已有证据，不覆盖教师选择的判定或错误位置。
- F6：教师明确提交“确认”或“改判”后，该判定作为最终评分依据；系统不能因机器仍存在软性告警而再次否决教师结论，也不能自行改变教师确认的得分。
- F7：当前已有的待复核运行在教师再次提交时应用同一规则，不要求重新上传、重新识别或重新批改。
- F8：教师明确提交确认或改判后，`MISSING_EVIDENCE`、`UNCERTAIN_ERROR_LOCATION`、`LOW_RECOGNITION_CONFIDENCE`、`MODEL_UNABLE_TO_JUDGE`、`MODEL_TOOL_CONFLICT`、`SCORE_INCONSISTENCY`、`DEPENDENCY_CONTRADICTION` 及其他评分审计原因均不得阻止复核完成。
- F9：系统仍须执行评分审计，但审计结果降级为教师可见且可追溯的告警；最终分数、逐项判定和依赖判定以本次教师确认后的结果为准。
- F10：教师确认覆盖评分审计告警时，系统必须保存审核动作、审核原因、全部被覆盖的告警类型和关联题目，形成可追溯记录。
- F11：同一题仍有其他未完成复核项时，该题保持待复核；最后一项复核完成后，该题进入最终状态。全部题目复核完成后自动进入错题报告生成流程。
- F12：教师确认的错题缺少可靠错误位置时，报告仍应生成；报告保留题目、得分、教师结论和文字说明，但不绘制虚假的错误框或红圈。
- F13：自动批改阶段仍执行严格审计并进入待复核；只有教师主动提交的确认或改判可以把全部评分审计告警降级为记录并完成复核。
- F14：复核接口只可因请求无法执行而拒绝，例如复核项不存在、已被处理、请求格式无效、改判没有提供任何修改或覆盖键不存在；不得再因教师确认后的评分审计结果拒绝。

## 非功能需求

- N1：证据共享必须是确定性的；相同输入产生相同关联结果。
- N2：不得修改原始学生答卷、识别文字或历史审核记录；题目得分只能由教师明确改判产生变化。
- N3：不得停止或删除评分审计；自动判定阶段继续按原规则产生复核项，教师提交阶段改为记录告警而非阻断。
- N4：证据区域可以被多个空位引用，不复制或修改原始区域文件。
- N5：教师覆盖告警的规则必须同时作用于已有待复核运行和新运行，且无需重新识别或重新评分。
- N6：复核提交必须保持幂等，重复请求不能重复扣分、重复关闭其他复核项或产生相互矛盾的报告状态。

## 不做的事

- 不通过大模型猜测某个区域是否属于某个空位。
- 不为无法内容匹配的空位自动编造证据。
- 不在本次改动中新增逐空位手动画框界面。
- 不取消自动批改阶段的证据与评分审计；仅允许教师明确审核后带审计记录地覆盖全部评分审计告警。
- 不允许系统在没有教师明确提交的情况下自动忽略任何评分审计告警。
- 不重新执行识别、评分或改变既有总分。

## 验收标准

- AC1：给定一个识别区域“失去 异种 吸引”和三个实际答案相同的空位，B1、B2、B3 最终都引用该区域。
- AC2：区域文字包含换行或常见分隔符时，三个空位仍能完成确定性内容匹配。
- AC3：空答案或区域文字不包含实际答案时，该空位保持无自动证据关联。
- AC4：已有证据的空位和教师选择的错误位置在共享处理后保持不变。
- AC5：教师修改的正确/错误判定和由此计算的得分不被证据共享逻辑改变。
- AC6：当前第 9 题的教师确认不再因 B2、B3 缺少证据而返回评分矛盾。
- AC7：当第 9 题仍有无法自动匹配的空位时，教师明确确认仍可关闭该复核项，并记录被覆盖的 `MISSING_EVIDENCE`。
- AC8：教师确认缺少可靠错误位置的低分或零分题后，复核可以完成；报告包含该题的文字信息且不生成虚假红圈。
- AC9：同一题有多个复核原因时，完成一个复核项不会误关其他项；完成最后一项后题目才进入最终状态。
- AC10：最后一项教师复核完成后，错题报告自动生成，不再因教师已确认的证据或位置软性告警返回冲突。
- AC11：教师确认后的结果即使仍存在分项合计、依赖关系或其他评分审计告警，复核也能成功完成；响应和审计记录明确列出被教师覆盖的告警。
- AC12：未经过教师确认的自动批改结果仍须满足原有证据和错误位置完整性要求。
- AC13：全部填空批改单元测试、教师复核测试、报告生成测试和相关 API 集成测试通过。
- AC14：复核项不存在、已处理、请求格式无效或覆盖键不存在时仍返回明确的接口错误，且不写入部分结果。
- AC15：类型检查、后端静态检查和生产构建通过。
