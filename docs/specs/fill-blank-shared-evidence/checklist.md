# 多填空共享证据与教师审核优先 Checklist

> 每项必须由自动化测试、数据库断言或实际产物验证。评分审计告警只能记录，不能作为教师提交失败的理由。

## 已完成基础能力

- [x] 单个识别区域包含“失去、异种、吸引”时，B1、B2、B3 可确定性共享同一区域。
- [x] 空白、换行、常见分隔符及全半角差异不影响确定性内容匹配。
- [x] 空答案、不匹配答案、无共享候选时不自动编造证据。
- [x] 已有独立证据、教师判定和教师错误位置不会被共享逻辑覆盖。
- [x] 新批改和历史复核共用共享证据规则，逐题与逐空结果持久化一致。
- [x] 既有共享证据目标测试、完整后端测试、静态检查、类型检查和生产构建曾通过。

## 教师审核绝对优先

- [ ] 教师点击“确认当前判定”后，即使仍存在 `MISSING_EVIDENCE`，复核也成功提交，不返回评分矛盾。（AC6、AC7）
- [ ] 即使仍存在 `UNCERTAIN_ERROR_LOCATION`，教师确认也成功提交。（AC8）
- [ ] `LOW_RECOGNITION_CONFIDENCE`、`MODEL_UNABLE_TO_JUDGE`、`MODEL_TOOL_CONFLICT` 不阻止教师确认。（F8）
- [ ] `SCORE_INCONSISTENCY` 不阻止教师确认，最终分数采用教师确认后的结果。（AC11）
- [ ] `DEPENDENCY_CONTRADICTION` 不阻止教师确认，依赖矛盾作为告警保存。（AC11）
- [ ] 其他评分审计原因出现时同样只记录、不拦截。（F8、F9）
- [ ] 教师改判后的逐项状态和重新计算分数作为最终结果，不被审计逻辑改回。（F6）
- [ ] 确认和改判都要求教师明确提交；系统不得自动替教师关闭复核项。（F13）

## 教师裁决审计记录

- [ ] 每次成功复核向题目 `tool_observations_json` 追加一条有效 `teacher_review` 记录。（F10）
- [ ] 记录包含复核项 ID、原复核原因、确认/改判动作、教师说明、全部告警原因和具体描述。（F10）
- [ ] `grading_review_items.resolution_json` 同步保存被覆盖原因与审计告警。（F10）
- [ ] `review_resolved` 事件保存同一组教师裁决信息。（F10）
- [ ] 题目结果、复核项和事件三处信息一致且可追溯。（N2）
- [ ] 没有审计告警时仍保存教师明确确认记录，供报告生成识别人工审核状态。
- [ ] 多次复核同一题时保留全部历史裁决，读取报告说明时使用最近一次有效记录。

## 请求级错误与事务安全

- [ ] 复核项不存在时返回明确 404，且不写入任何结果。（F14、AC14）
- [ ] 复核项已处理时返回明确 409，不重复追加裁决或修改分数。（N6、AC14）
- [ ] 请求格式无效、确认请求夹带改判字段、改判没有修改内容时返回明确校验错误。（F14）
- [ ] 填空或评分点覆盖键不存在时返回明确错误，不产生部分写入。（F14、AC14）
- [ ] 数据库事务失败时复核项、题目结果、明细和事件全部回滚。（N6）
- [ ] 以上请求级错误与评分审计告警在代码和响应中明确区分。

## 多复核项状态推进

- [ ] 同一题有多个开放复核项时，确认当前项不会误关其他项。（AC9）
- [ ] 当前项关闭后，同题仍有开放项则题目保持 `needs_review`，响应返回准确的 `remainingReasons`。（AC9）
- [ ] 同题最后一项关闭后题目才进入 `final`。（F11）
- [ ] 全卷仍有其他开放项时运行保持 `needs_review`，不会提前生成报告。（F11）
- [ ] 全卷最后一项关闭后 `open_review_count` 变为 0，运行进入 `generating_annotation`。（AC10）
- [ ] 总分和 `result_revision` 在每次有效复核后准确刷新，旧产物标记为过期。（N6）

## 批注生成

- [ ] 非满分题没有错误位置但存在有效教师裁决时，批注生成不再返回 `ANNOTATION_ERROR_LOCATION_REQUIRED`。（AC8、AC10）
- [ ] 无错误位置时不绘制红圈、错误框、引线或虚构坐标。（F12）
- [ ] 有真实错误位置时仍按原逻辑绘制错误标记。
- [ ] 没有教师裁决的自动结果缺少错误位置时仍触发原有严格校验。（AC12）
- [ ] 生成后的批注 PDF 对应最新 `result_revision` 并标记为当前产物。

## 错题报告生成

- [ ] 无错误位置的教师审核错题仍出现在报告中，包含题号、得分、错误原因、知识点和订正建议。（F12）
- [ ] 报告错误原因包含最近一次教师审核说明，且不超出字段长度限制。
- [ ] 无区域时 `evidenceRegionId` 为空并省略截图，不伪造或错绑其他区域。（F12）
- [ ] 报告不输出完整答案、完整解题过程或虚构证据。
- [ ] 最后一项复核后自动生成错题报告 PDF，无需教师再次点击。（AC10）
- [ ] 报告完成后运行状态为 `completed`，批注与错题报告两类产物均为当前版本。

## 前端按钮反馈

- [ ] 点击确认后按钮立即显示“正在保存复核…”并禁用，防止重复点击。
- [ ] 成功且有剩余项时显示剩余数量并自动定位下一复核题。
- [ ] 最后一项成功后显示正在生成结果文件的提示。
- [ ] 请求级失败时恢复按钮并显示服务端明确错误，不出现点击无反应。
- [ ] 报告生成失败时页面显示可理解的失败原因和可用重试入口。
- [ ] 报告完成后页面能够看到或打开最新批注和错题报告。

## 当前真实场景的隔离复现

- [ ] 场景 A：复现第 9 题 4/4 且 B2、B3 缺证据 → 教师确认 → 成功关闭当前复核项并记录 `MISSING_EVIDENCE`，分数保持 4/4。
- [ ] 场景 B：复现第 12 题 4/7 且无错误位置、模型无法判断 → 教师确认 → 所有相关告警均不拦截。
- [ ] 场景 C：复现第 13 题 0/10 且无错误位置 → 教师确认 → 错题报告收录该题但不绘制红圈。
- [ ] 场景 D：复现第 14、15 题低置信度、位置不确定 → 逐项确认 → 最后一项后自动生成两份产物。
- [ ] 场景 E：构造分项合计不一致及依赖矛盾 → 教师确认 → 接口成功，告警完整保存，报告仍可生成。
- [ ] 场景 F：同一复核项重复提交 → 第二次被请求级校验拒绝，首次教师结论保持不变。
- [ ] 所有场景使用隔离测试数据库，不代替教师操作真实答卷。
