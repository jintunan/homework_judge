# 就近批注与 AI 错题诊断 Spec

## 背景

当前批注试卷在答案区域附近没有足够空白时，会把绿色对勾或部分分标记移到页面远处，并绘制一条长引导线连接答案。实际效果是标记与答案分离，红色引导线穿过题目正文，影响阅读。

当前错题分析报告没有独立分析学生错误。它直接从既有批改结果中摘取 `reason`，把题干截断后作为“相关知识”，把 `P1`、`FINAL_ANSWER` 等内部评分点编号作为“已经掌握”，再按题型拼接固定建议。这无法回答学生为何出错、哪个知识没有掌握以及应该怎样改进。

## 目标

- 让正确标记始终出现在对应学生答案或作答证据附近，一眼能看出标记属于哪道答案。
- 批注试卷和页面预览都不再出现连接答案与标记的红色或其他颜色引导线。
- 对每道非满分题调用模型进行一次独立、面向学生的错误诊断，而不是复用或拼接既有批改说明。
- 错题报告给出具体错误类型、形成错误的原因、未掌握到位的知识和可执行的改进建议。

## 功能需求

- F1：满分题的绿色对勾必须以该题首个可靠学生答案证据为锚点，优先放在答案右侧，其次选择答案左侧、上侧或下侧的邻近空白；不能移动到远离答案的页面边栏。
- F2：当答案周围没有完全无冲突的空白时，系统应缩小标记或选择距答案最近的边缘位置，仍保持标记与锚点局部相邻；不能以长距离移动加引导线作为回退方案。
- F3：批注图片、批注 PDF、批注预览数据和网页叠加预览均不得包含引导线。现有错误位置圈、部分分标记和待复核题不落最终标记的规则保持不变。
- F4：每道非满分题的错题分析必须由独立的模型诊断步骤生成。诊断输入可以包含题目、题型、标准答案与解析、学生识别作答、学生作答证据图、最终得分、评分点状态、依赖关系和教师复核事实，但不得把既有批改 `reason` 文本作为待复制的分析内容传入。
- F5：模型对每道非满分题必须输出：错误类型、具体错误原因、知识薄弱点、已经掌握的内容和改进建议；整份试卷还必须输出基于所有错题归纳的总体分析。
- F6：错误类型至少覆盖计算不认真、概念或知识未掌握、方法未掌握、审题错误、表达或书写问题、漏答或步骤不完整，以及证据不足无法可靠归因。模型只能在证据支持时使用“计算不认真”等主观归因，不能无依据推测学生态度。
- F7：“具体错误原因”必须结合学生实际作答与正确要求说明首个关键偏差；“知识薄弱点”必须写成人可读的知识或能力描述，不能用题干截断文本代替；“已经掌握”不能显示 `P1`、`P2`、`FINAL_ANSWER` 等内部键；“改进建议”必须与该题诊断对应且可执行。
- F8：诊断模型输出必须经过严格结构校验，并按题目 ID 与非满分题一一对应。缺题、多题、重复题、非法类型、空字段或超长字段均视为本次报告生成失败。
- F9：若诊断模型未配置、请求失败或输出校验失败，系统不得退回到旧批改文本拼接或固定题型模板；本次生成应进入可重试失败状态，并向用户显示可理解的失败原因。
- F10：满分试卷不调用错题诊断模型，仍生成“本次没有需要订正的题目”的报告；只有非满分题进入逐题错题列表。
- F11：报告 JSON、接口预览数据和 PDF 使用同一份经校验的诊断结果。PDF 中逐题展示“错误类型、错误原因、知识薄弱点、已经掌握、改进建议”，并继续显示最终得分和真实学生作答裁剪图。
- F12：重新生成同一结果版本时，使用当次模型诊断结果生成一致的报告数据和 PDF；结果版本变化后，旧生成物继续按现有规则失效。

## 非功能需求

- N1：批注位置计算必须是确定性的；同一页面尺寸、答案锚点和占用区域应得到相同位置。
- N2：所有标记必须完整位于学生原始页面边界内，并尽量避免遮挡其他题目的作答证据。
- N3：模型温度保持为零，提示词和输出结构有显式版本号，便于回归与审计。
- N4：模型输出不能修改分数、正误或教师复核结论；诊断只解释已经最终确定的评分事实。
- N5：报告不展开完整标准答案或完整解题过程，不把内部评分实现细节暴露给学生。
- N6：现有学生原图不得被修改；批注与错题报告仍生成独立副本。
- N7：不覆盖工作区中与本需求无关的现有修改和临时文件。

## 不做的事情

- 不改变单选、多选、填空和计算题的判分算法、分数或教师复核流程。
- 不新增教师手工编辑 AI 错题诊断的界面。
- 不引入新的数据库表或历史诊断管理页面；诊断结果随现有错题报告 JSON 和生成物预览保存。
- 不要求模型诊断满分题，也不为学生生成完整标准解答。
- 不重新设计错误圈和部分分三角形的视觉样式，只移除引导线并修正答案附近的标记布局。

## 验收标准

- AC1：给定页面中部、左边缘、右边缘、顶部和底部的答案框，绿色对勾均完整位于页面内，且与对应答案框相邻；不会落到远端页面边栏。（对应 F1、F2）
- AC2：批注标记数据不再含可绘制的引导线，生成的 JPG/PDF 与网页 SVG 预览均没有连接线。（对应 F3）
- AC3：错误位置圈、部分分标记、满分对勾和待复核隐藏规则的现有行为均通过回归测试。（对应 F3）
- AC4：含非满分题时，测试模型每道题收到题目、标准要求、学生作答、结构化评分事实及可用证据图，但输入中不含既有决策的 `reason` 文本。（对应 F4）
- AC5：测试模型返回两道不同错误的诊断后，报告分别显示例如“计算不认真”和“概念未掌握”等有证据支持的类型、具体原因、知识薄弱点与针对性建议，而不是相同固定模板。（对应 F5、F6、F7）
- AC6：报告中不存在 `P1`、`P2`、`FINAL_ANSWER` 等内部评分点键，也不会把题干前若干字直接作为知识点。（对应 F7）
- AC7：模型返回缺题、重复题、未知题目、非法错误类型、空字段或无效 JSON 时，生成失败且可重试，不生成由旧 `reason` 拼接的报告。（对应 F8、F9）
- AC8：模型超时或未配置时，运行进入带明确错误码和用户可读提示的失败状态；重试后可继续生成。（对应 F9）
- AC9：所有题满分时不调用模型，报告成功生成且错题列表为空。（对应 F10）
- AC10：错题报告预览 JSON 与 PDF 的总体分析和逐题诊断一致，并保留最终分数与真实作答裁剪图。（对应 F11、F12）
- AC11：专项单元测试、生成物流集成测试、Python 类型检查、静态检查和编译检查通过，且无新增空白错误。（对应 N1-N7）
