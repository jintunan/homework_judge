# 就近批注与 AI 错题诊断 Checklist

> 每一项都必须通过运行代码、检查生成物或观察真实页面验证。本文档当前是验收设计，不代表实现已经通过；开发完成前不得预先勾选。

## 批注位置与视觉

- [ ] 页面中部答案的绿色对勾位于答案右侧邻近区域，未移动到页面边栏。（验证：布局单元测试 + 真实批注页；对应 AC1）
- [x] 靠近页面左、右、上、下边缘的答案都能得到完整页内对勾。（验证：四个边缘参数化测试；对应 AC1）
- [x] 超宽答案框或答案周围已有标记时，系统缩小标记或选最近局部位置，标记到答案的距离不超过规定阈值。（验证：冲突与回退单元测试；对应 AC1）
- [x] 后端标记 JSON 中不存在可绘制的引导线字段或数据。（验证：`marks.json` 断言；对应 AC2）
- [x] 生成的批注 JPG 和 PDF 没有连接答案与对勾/部分分标记的红线或其他引导线。（验证：像素测试 + PDF 视觉检查；对应 AC2）
- [x] 网页 SVG 批注叠加层不渲染 `<line>`，且对勾、错误圈和部分分标记仍正常显示。（验证：UI DOM 断言；对应 AC2、AC3）
- [x] 零分题仍显示错误位置圈，部分分题仍显示错误位置与分数标记，待复核题仍不显示最终标记。（验证：布局回归测试；对应 AC3）
- [x] 学生原图哈希和页面尺寸在批注生成前后保持不变。（验证：渲染单元测试；对应 N6）

## AI 错题诊断输入

- [x] 每道非满分题向模型提供完整题目、题型、标准答案快照、学生最终识别作答、最终分数和结构化评分事实。（验证：测试模型捕获请求；对应 AC4）
- [x] 有效的学生作答证据图按题目分组传给模型；无图时请求明确标注证据缺失，不伪造图像。（验证：多模态请求内容断言；对应 AC4）
- [x] 模型请求文本中不包含 `decisions_json.reason` 的哨兵文本或其他旧批改自然语言理由。（验证：请求内容搜索；对应 AC4）
- [x] 教师复核事实可进入诊断输入，但提示要求综合改写，不能直接替代诊断。（验证：提示词与请求快照；对应 AC4）
- [x] 全部题目满分时不调用错题诊断模型。（验证：零调用计数；对应 AC9）

## AI 输出质量与约束

- [x] 合法模型结果为每道非满分题输出错误类型、具体错误原因、知识薄弱点、已掌握内容和改进建议。（验证：输出模型单元测试；对应 AC5）
- [x] “计算不认真”案例的诊断指出实际算术、符号、抄写或验算偏差，并保留其正确方法或知识部分。（验证：固定测试模型结果 + 报告断言；对应 AC5）
- [x] “知识未掌握”案例指出具体概念或适用条件，不使用与粗心题相同的固定建议。（验证：两题对比断言；对应 AC5）
- [x] 证据不足时模型使用“无法可靠归因”，不无依据判断学习态度或能力。（验证：提示词约束 + 固定输出测试；对应 F6）
- [x] 报告学生可见字段不存在 `P1`、`P2`、`FINAL_ANSWER` 等内部键。（验证：JSON/PDF 文本检查；对应 AC6）
- [x] “知识薄弱点”不是题干固定长度截断，“已经掌握”是人可读描述而非内部评分点列表。（验证：输入题干哨兵与输出断言；对应 AC6）
- [x] 报告不包含完整标准答案或完整解题过程。（验证：契约校验和 PDF 文本检查；对应 N5）

## 严格校验与失败重试

- [x] 模型返回无效 JSON 时诊断被拒绝，不生成错题报告。（验证：异常单元/集成测试；对应 AC7）
- [x] 模型缺少输入题目、重复题目或返回未知题目时诊断被拒绝。（验证：三类题目集合测试；对应 AC7）
- [x] 非法错误类型、空字段、超长字段或内部键泄露时诊断被拒绝。（验证：结构与内容校验测试；对应 AC7）
- [x] 诊断校验失败不会退回旧批改理由或固定题型建议。（验证：失败后 artifact 与磁盘检查；对应 AC7）
- [x] 模型未配置或超时时，运行进入 `failed` 且 `retryable=1`，错误码和消息明确指向错题诊断。（验证：集成测试；对应 AC8）
- [x] 失败后模型恢复并重试，运行可继续生成 current 错题报告并进入 `completed`。（验证：重试集成测试；对应 AC8）

## 报告一致性

- [x] 全满分报告成功生成，显示没有需要订正的题目，逐题列表为空。（验证：报告单元测试；对应 AC9）
- [x] 每道非满分题的报告 JSON、接口预览和 PDF 使用相同诊断文本。（验证：跨生成物内容对比；对应 AC10）
- [x] PDF 逐题显示错误类型、错误原因、知识薄弱点、已经掌握和改进建议。（验证：PDF 文本提取与视觉检查；对应 AC10）
- [x] PDF 保留最终题号、最终分数和真实学生作答裁剪图。（验证：报告数据与图片文件断言；对应 AC10）
- [x] 总体分析由整份 AI 诊断结果提供，并与逐题问题和优先建议一致。（验证：预览 JSON 与 PDF 对比；对应 AC10）
- [x] 同一结果版本的报告数据、PDF 和预览使用同一次经校验诊断，结果版本更新后旧生成物失效。（验证：生成物版本集成测试；对应 AC10）

## 端到端场景

- [ ] 场景 1：包含多个满分选择题的真实试卷完成批改后，下载的批注 PDF 中每个绿色对勾都贴近对应答案，整页没有穿过正文的引导线。（对应 AC1、AC2）
- [ ] 场景 2：学生方法正确但局部算错时，错题报告将其诊断为计算不认真或等价类型，指出具体算错位置、肯定正确方法并给出验算建议。（对应 AC5、AC10）
- [ ] 场景 3：学生误用概念或公式适用条件时，错题报告诊断具体知识缺口，建议针对该概念复习和练习，而不是复用计算粗心模板。（对应 AC5、AC6、AC10）
- [ ] 场景 4：诊断模型暂时失败时，页面显示可重试失败；恢复后重试成功，最终报告没有旧批改文本拼接痕迹。（对应 AC7、AC8）
