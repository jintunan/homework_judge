- [ ] 删除 ready 答卷后主记录及页面、修订、区域、答案、逐空答案、批改、复核、事件和生成物记录

## 草稿生成范围与输入

- [ ] 单选、多选、填空、计算题显示“重新生成答案和批改设置”；简答、待确定和重复题不显示

- [ ] 服务端拒绝简答、待确定和重复题的直接生成请求
  （验证：参数化 API 测试返回稳定 409 和明确错误码）。
- [ ] 模型输入只包含当前有效题目、当前正式设置、当前题全部题框裁剪和相关参考答案文本/来源页
  （验证：模型 stub 捕获请求，断言没有其他题目、学生答案和客户端文件路径）。
- [ ] 跨页当前题的所有题框片段按页码和片段顺序发送，答案页只能来自同任务 answer 文档
  （验证：两页题框与两页答案 fixture，检查内容顺序和越界/异任务拒绝）。
- [ ] 生成运行记录包含题目/匹配/题框/配置捕获、模型、提示词版本、原始响应和用量
  （验证：成功和失败后查询 `runs` 对应字段）。
- [ ] 生成成功仅把运行推进到 `preview_ready`，不更新答案、解析、配置、评分细则、学生处理或批改
  （验证：生成前后比较所有正式表业务快照）。
- [ ] 模型超时、鉴权失败、无效 JSON 或结构校验失败时正式数据保持不变且运行记录失败原因明确

## 四题型草稿正确性

- [ ] 单选草稿只有一个现有合法选项，多选草稿至少两个且没有未知选项
  （验证：合法/空/多单选/未知标签模型响应单测）。
- [ ] 所有草稿标准答案和解析非空，满分严格等于当前题满分
  （验证：缺字段和不同满分响应被拒绝）。
- [ ] 填空草稿键为连续 B1…Bn、顺序连续、每空有标准答案、分值为正且合计等于总分
  （验证：缺键、重复键、少答案、零分和合计冲突响应被拒绝）。
- [ ] 示例电现象题识别三个作答空位，草稿依次包含“电荷转移”“守”“CD”或明确等价答案
  （验证：使用题图/参考答案 fixture 的模型 stub，观察三行预览）。
- [ ] 题干标记、视觉空位、答案结构或锚点数冲突时预览显示具体警告，不静默采用更少空位
  （验证：构造 2/3/2/0 信号，检查选择 3 空及 warning）。
- [ ] 计算题评分点总和、依赖、`FINAL_ANSWER` 和现行评分政策均通过既有校验
  （验证：合法替代解法草稿通过；未知依赖、环、分值或最终答案占比错误被拒绝）。

## 预览、并发与应用

- [ ] 预览按题型同时展示当前答案/解析/设置和新草稿，并清楚标识变化
  （验证：视觉/DOM 检查 choice、fill、calculation 三种布局）。
- [ ] 点击取消后关闭预览，当前正式数据和查询缓存内容不变
  （验证：取消后重新打开当前设置，并确认未调用 apply）。
- [ ] 应用只提交题目 ID 和运行 ID，不接受客户端改写后的草稿字段
  （验证：检查客户端请求体与后端路由模型）。
- [ ] 应用前题目内容、答案关联、题框、逐空版本或冻结细则任一变化，旧草稿均返回
  `ANSWER_GRADING_DRAFT_SUPERSEDED` 且不覆盖新值
  （验证：对每种捕获事实分别修改并调用 apply）。
- [ ] 有活动学生识别或批改时生成预览可完成，但应用被稳定冲突码阻止
  （验证：种入活动状态，比较应用前后快照）。
- [ ] 应用成功仅更新当前题答案、解析和正式配置，其他题的内容、设置、确认状态和排序完全不变
  （验证：为相邻题建立哨兵快照并逐字段比较）。
- [ ] 原题已确认时应用后仍确认；原题待确认时不被草稿应用自动确认
  （验证：两种初始状态的集成测试）。
- [ ] 应用保留参考答案条目来源，旧逐空/评分细则版本仍可查询，新版本成为正式可用版本
  （验证：检查 match 关联、版本列表、当前指针和冻结状态）。
- [ ] 同一草稿第二次应用被拒绝，运行阶段保持 `applied`，审计只有一次有效应用
  （验证：连续两次 apply，检查响应和审计计数）。
- [ ] 应用事务中的任意配置写入或失效步骤失败时，答案、配置、运行阶段和下游指针全部回滚
  （验证：注入事务中间失败并比较完整快照）。

## 端到端场景

- [ ] 场景 1：上传两份学生答卷并完成其中一份批改 → 删除已批改答卷 → 其原卷、识别、评分和报告
  全部消失 → 另一份答卷和任务模板仍可正常查看与处理。
- [ ] 场景 2：打开示例 5 分电现象题 → 重新生成 → 预览显示三空“电荷转移/守/CD”和
  1.67/1.67/1.66 → 应用 → 旧学生结果标记失效 → 重新处理后按三空产生新识别和批改。
- [ ] 场景 3：模型仍少给一空 → 教师在正式设置中增加第三空 → 系统自动均分 → 填入第三空答案 CD →
  保存成功 → 学生答卷被要求按新设置重新处理。
- [ ] 场景 4：生成预览后另一窗口修改当前题答案或题框 → 原窗口点击应用 → 明确提示草稿已过期，
  新修改保持不变，重新生成后才能应用。
