# 学生答卷删除与当前题答案/批改设置重生成 Spec

## 背景

当前系统存在三个直接影响教师工作的缺口：

1. 误传、重复上传或不再需要的学生答卷无法单独删除；只能删除整个任务，连同空白试卷、
   参考答案和其他学生答卷一起移除。
2. 当前题的标准答案、解析或批改设置不理想时，教师只能逐项手工修改，不能结合当前题
   原图和已上传的参考答案重新生成一套建议。
3. 填空题空位数识别不足时，教师虽然可以手动增加空位，但新增空位的默认分值会使逐空
   分值合计超过本题满分，保存被拒绝。实际案例中题面有三个作答空位，系统只生成两个，
   且把“电荷转移”和“守”合并为同一空，导致正式批改设置无法建立。

## 目标

- 教师可以永久删除一份指定的学生答卷，包括它的原文件、页面图、识别与处理历史、批改
  结果及生成的批注/错题报告，同时保留任务模板和其他学生答卷。
- 教师可以在题目复核页为当前题重新生成标准答案、解析和批改设置草稿。生成时可参考
  当前题原图、当前题结构以及已上传参考答案中的关联内容。
- 新草稿必须先与当前内容对比预览；只有教师明确应用后，才替换当前答案和批改设置。
- 重生成只支持单选题、多选题、填空题和计算题；重复题、简答题和待确定题型不提供入口。
- 填空题必须综合题面可见作答位置、识别题干和参考答案判断空位数。教师仍可手动增删空位；
  每次增删后按本题总分确定性重新均分，最后一空承接小数尾差。
- 应用新草稿后保留已有学生处理和批改历史作为证据，但旧识别、旧评分和旧报告不再作为
  当前结果，相关学生答卷必须按新版本重新识别并批改。

## 功能需求

### 学生答卷删除

- F1：学生答卷列表中的每一项提供独立删除入口；删除入口不能误触发该答卷的选择或进入
  批改工作台。
- F2：点击删除后显示确认对话框，明确展示学生姓名/学号或文件名，并说明原卷、识别历史、
  批改结果与报告将永久删除且无法恢复。教师确认后才执行删除，取消则不产生任何变化。
- F3：允许删除上传中、对齐中、识别中、待复核、已批改或失败状态的答卷。删除前先停止
  仅属于该答卷的后台处理、自动批改和报告生成任务，不影响其他答卷或任务级工作。
- F4：删除必须移除该答卷数据库主记录以及依附于它的页面、处理修订、配准修订、题目区域、
  学生答案、逐空答案、自动批改尝试、批改运行、逐题结果、复核记录、事件和生成物记录。
- F5：删除必须同时移除该答卷的上传文件、转换后的学生页面图，以及所有批改运行生成的
  批注试卷和错题报告文件；任务的试卷、参考答案、模板页面和其他学生答卷文件保持不变。
- F6：删除成功后列表立即移除该答卷。若删除的是当前选中项，界面选择相邻的下一份可用
  答卷；没有剩余答卷时回到“还没有学生答卷”的空状态。
- F7：答卷不存在时返回稳定的“不存在”错误；文件安全校验或清理失败时不得静默报告成功，
  页面显示可理解的错误并允许重试。

### 当前题答案和批改设置草稿

- F8：题目复核页只在当前题为单选、多选、填空或计算题且未标记为重复时，提供“重新生成
  答案和批改设置”入口。简答题、待确定题和重复题不显示该操作。
- F9：生成操作读取当前有效题号、题干、选项、题型和满分，当前题已确认题框内的题目原图，
  当前已关联参考答案条目及其答案页图像，并把现有答案、解析和正式批改设置作为对比上下文。
  不发送其他题目的学生答案或无关学生数据。
- F10：模型一次生成结构化草稿：
  - 单选/多选：标准选项答案、解析和本题满分设置；
  - 填空：整题标准答案、解析、完整空位清单、逐空类型、标准答案、同义答案和逐空分值；
  - 计算：标准答案、解析、本题满分和满足现行评分政策的评分点、分值与依赖关系。
- F11：填空题空位数必须优先依据题目原图中所有实际作答位置，结合识别题干中的横线/空位
  标记和参考答案的结构交叉判断；不同信号冲突时不能静默少生成空位，草稿必须显示警告供
  教师检查。所给 5 分电现象题应生成三个空：“电荷转移”“守”“CD”（或等价可接受答案）。
- F12：生成结果以只读的新旧对比预览呈现，至少显示标准答案、解析、满分以及该题型特有的
  逐空配置或计算题评分点。生成失败、超时或返回无效结构时保留当前正式内容不变，并允许
  重新生成或取消。
- F13：预览提供“应用草稿”和“取消”操作。取消只关闭预览；应用必须再次校验草稿对应的
  题目、题框、答案关联和批改配置仍是生成时的版本，过期草稿被拒绝并提示重新生成。
- F14：应用成功后原子替换当前题的教师答案、解析和正式批改设置；其他题目的内容、答案、
  批改设置、确认状态和排序不变。旧配置与旧评分细则保留为历史版本。
- F15：应用已经通过模型结构校验和教师确认的草稿。若当前题在生成前已确认，则应用后继续
  保持已确认；若原本待确认，则仍保持待确认，应用草稿不代替对题干/题型的完整确认。
- F16：生成和应用均记录可追踪信息，包括当前题、输入版本、参考答案来源、模型、提示词版本、
  原始返回、用量、教师应用动作和应用结果；同一草稿不能被重复应用。
- F17：任务中存在正在运行的学生识别或批改时，可以生成预览但不能应用；页面明确提示先等待
  当前处理结束，避免新设置与正在提交的旧结果竞态。

### 填空设置手动补救与下游失效

- F18：填空设置继续支持手动增加和删除空位。增删后空位键与顺序自动重排为连续的 B1…Bn，
  并立即按本题满分重新分配每空分值。
- F19：均分精确到两位小数，前 n-1 空按四舍五入取两位，最后一空等于本题满分减去前面各空之和，
  保证逐空分值总和严格等于本题满分。例如 5 分三空为 1.67、1.67、1.66。
- F20：自动均分后教师仍可逐空修改分值；保存前界面显示逐空合计与本题满分的差额。答案为空、
  分值非正数、键或顺序不连续、逐空合计不等于本题满分时，在对应字段附近显示中文校验原因，
  不能只返回笼统的“请求失败”。
- F21：应用新答案/批改设置或教师保存有实质变化的逐空配置后，所有依赖旧配置的当前学生处理
  修订解除“当前”身份，学生答卷回到待重新处理状态；旧批改运行和生成物标记为失效但不删除。
  教师重新处理后产生新的识别修订和批改运行。

## 非功能需求

- N1：删除只允许操作服务器解析并验证位于运行数据目录内的精确路径，不接受客户端文件路径，
  不允许路径穿越或删除任务/数据根目录。
- N2：删除的后台任务停止、文件清理与数据库级联应保持可解释的一致性；不能出现接口返回成功
  但答卷仍可访问的状态，也不能因文件删除失败而先删除数据库事实。
- N3：草稿生成不修改任何正式业务数据；应用在单个数据库事务中完成答案、配置、版本失效和
  审计写入，任一校验失败时全部保持原值。
- N4：模型等待期间不持有数据库事务；应用前使用捕获版本/内容哈希做乐观并发校验，防止晚到
  草稿覆盖教师后续编辑。
- N5：模型输出必须经过严格结构、题型、答案、分值和评分政策校验；客户端不能伪造或修改运行
  记录中的模型草稿后直接应用。
- N6：只发送完成当前题所需的最小图像和文本上下文；模型调用失败不得影响现有答案、配置或
  学生历史。
- N7：删除、生成、应用、手动增删空位和失效行为均须可通过模拟模型与临时数据目录完成自动化
  测试，不依赖真实外部模型。
- N8：现有整卷识别、单题重新识别、题框复核、答案手工编辑、评分细则生成/冻结、学生处理、
  自动批改及整任务删除行为保持兼容。

## 不做的事情

- 不提供学生答卷回收站、软删除、恢复或批量删除。
- 不删除任务模板、参考答案、其他学生答卷或与当前答卷无关的后台任务。
- 不支持整份试卷一次性重生成答案和批改设置。
- 不为简答题、待确定题或重复题生成答案/批改草稿。
- 不在生成草稿后自动应用，也不自动确认原本待确认的题目。
- 不在应用后自动重跑所有学生答卷；系统只明确标记失效，由教师按现有入口发起重新处理。
- 不自动创建独立的逐空视觉锚点；缺少单空锚点时继续使用完整题框作为共享识别上下文。
- 不改变计算题现行最终答案占比、替代解法和证据约束等评分政策。

## 验收标准

- AC1：删除一份已有识别和批改结果的学生答卷后，该答卷不再出现在列表，详情接口返回不存在，
  其数据库派生记录、原卷、页面图和报告文件均不存在；同任务其他答卷和模板文件仍可访问。
- AC2：删除正在处理的答卷时，仅该答卷相关后台任务被取消，删除成功，其他答卷处理继续运行。
- AC3：删除确认框取消后没有请求和数据变化；删除失败时保留列表项并显示服务端原因，可再次尝试。
- AC4：删除当前选中答卷后自动选择剩余相邻答卷；删除最后一份后显示空状态且不再请求旧详情。
- AC5：四类受支持题目显示重生成入口；简答、待确定和重复题不显示入口，服务端直接请求也被拒绝。
- AC6：点击重生成后，在模型成功返回前和预览期间，当前答案、解析、批改设置及学生结果均不变。
- AC7：预览清楚展示当前值与草稿值；点击取消后原值保持不变；点击应用后仅当前题切换为草稿答案、
  解析和正式批改设置。
- AC8：生成期间教师修改了当前题、答案关联、题框或配置时，旧草稿应用返回版本冲突，不覆盖新内容。
- AC9：模型超时、无效 JSON、题型不匹配、选择题答案无效、逐空总分不等或计算评分点不合规时，
  显示具体错误且不产生部分更新。
- AC10：示例电现象题以题面原图和参考答案生成三个空，“电荷转移”“守”“CD”分别进入三个逐空
  草稿项，不再把前两个答案合并为同一空。
- AC11：在 5 分填空题中从两空增加为三空时，界面立即显示 1.67、1.67、1.66；删除回两空时显示
  2.50、2.50，且教师可继续修改。
- AC12：第三空填写标准答案且各空合计为 5.00 后，保存批改设置成功；若标准答案缺失或合计不符，
  页面在对应位置说明原因。
- AC13：应用新草稿或保存实质变化的逐空配置后，旧学生处理修订不再是当前版本，旧批改运行和
  报告显示为失效；历史仍可核查，重新处理能产生新的当前识别和批改结果。
- AC14：草稿运行记录可以查到当前题、捕获版本、参考答案来源、模型、提示词版本、原始响应和用量；
  审计记录可以查到应用者和所应用的运行，同一草稿第二次应用被拒绝。
- AC15：类型检查、后端静态检查、数据库迁移测试、相关单元/集成/UI 测试及生产构建全部通过。
