# 学生答卷识别并发与计算题单次识别 Spec

## 背景

当前学生答卷处理会按题目顺序逐题等待视觉模型返回。一份 7 页、15 题的实际答卷最近两次识别约耗时 146 秒和 195 秒，而本地页面配准仅约 2 秒，主要等待来自远程模型调用。计算题还采用“先定位书写区域、再转写定位区域”的两段调用；在最近样本中，3 道计算题约占全部识别 Token 的 47%。

本次优化需要在不改变题框、证据、评分和历史版本语义的前提下，缩短单份学生答卷从开始识别到可进入自动批改的时间。

## 目标

- 单份学生答卷最多同时识别 3 道题，包括计算题。
- 计算题在正常路径中一次完成书写区域定位与对应内容转写。
- 当计算题单次结果不完整或不可信时，自动回退到兼容的定位与转写流程。
- 保持题目顺序、证据位置、识别状态、人工复核条件和原子提交行为不变。
- 提供足够的运行记录，能够区分单次成功、仅转写回退和完整回退。

## 功能需求

- F1：系统处理一份学生答卷时，应并行调度互相独立的题目识别，任意时刻最多有 3 道题处于识别执行状态。
- F2：选择题、填空题和计算题应共享同一个单份答卷并发上限；计算题不得因为处理步骤较多而被固定串行到其他题目之后。
- F3：并行识别完成后，系统应按照试卷原始题目顺序组装和保存结果，不得因完成先后改变题目、逐空结果或证据的顺序。
- F4：任一道题出现不可恢复的识别异常时，本次处理应保持现有失败语义，不得把部分并发结果提交为当前正式版本。
- F5：计算题的每个定位批次应在同一次正常模型调用中返回窗口状态、定位区域、区域对应转写、置信度和问题信息；正常结果不得再追加一次整题转写调用。
- F6：计算题单次结果只有在定位结构、区域归属、转写映射和证据引用均有效时才能作为正式识别结果。
- F7：若定位有效但转写缺失、映射错误或不可用，系统应复用已验证的定位区域，并调用兼容转写流程补全内容，避免重复定位。
- F8：若单次调用失败，或定位结构本身无效，系统应执行完整兼容回退：重新定位书写区域，再对有效区域转写。
- F9：可靠空白的计算题不得为了满足转写字段而额外调用模型；结果仍应保存为空白证据并遵循现有复核规则。
- F10：跨页或多批次计算题应逐批保存可追溯的模型输出和使用量；各批次正常完成定位与转写后，不再追加全题转写调用。
- F11：处理结果应记录计算题采用的路径：单次成功、复用定位后转写回退、完整两段回退或可靠空白。
- F12：现有全局模型限流仍然生效；若全局限制小于 3，实际并发应服从更严格的限制，不得绕过服务商保护。

## 非功能需求

- N1：单份答卷的题目级并发上限必须为 3，并且可以通过自动化测试观测，不依赖真实网络速度。
- N2：并发实现不得共享或修改题目之间的可变识别上下文，避免串题、证据错绑和结果顺序漂移。
- N3：计算题快速路径必须维持现有原图坐标、模板页、学生页、题框版本、配准版本和证据标识的可追溯性。
- N4：快速路径或回退路径产生低置信度、缺失证据或结构问题时，必须继续进入现有人工复核机制，不能用性能优化降低安全门槛。
- N5：单次成功路径相对于现有两段流程，每个计算题定位批次至少减少 1 次模型请求。
- N6：失败回退不得无限重试；仍应服从现有模型超时、重试和全局并发限制。
- N7：不得破坏现有处理修订、历史结果、原子提交和中断重试语义。
- N8：现有选择题、填空题、计算题定位、学生处理和评分回归测试必须继续通过。

## 不做的事

- 不把多道不同题目合并到同一个模型请求中。
- 不提高单份答卷超过 3 道题的并发上限。
- 不修改单选、多选、填空或计算题的评分规则。
- 不放宽页面配准、题框映射、证据完整性或人工复核标准。
- 不优化初始空白试卷识别、参考答案识别、批注 PDF 或错题报告生成。
- 不改变教师页面的题目、题框、逐空配置或评分细则工作流。
- 不删除或覆盖旧处理版本、旧识别结果和旧评分产物。

## 验收标准

- AC1：给定至少 6 道可独立识别的题目和可控延迟模型，观测到同时执行题目数达到 3，且任何时刻不超过 3。（对应 F1、F2、N1）
- AC2：让后续题目先返回时，最终保存结果仍严格遵循原始题目顺序，逐空和证据归属不变。（对应 F3、N2）
- AC3：并发中的一道题抛出不可恢复异常时，处理版本进入现有失败状态，数据库中不存在被提升为当前正式版本的部分结果。（对应 F4、N7）
- AC4：计算题返回结构完整的定位和转写时，只发生一次正常模型调用，转写内容、定位区域和证据引用正确保存。（对应 F5、F6、N3、N5）
- AC5：计算题定位有效但转写不可用时，不重新定位，只对已验证区域执行一次兼容转写，并记录“复用定位后转写回退”。（对应 F7、F11）
- AC6：计算题单次调用失败或定位结构无效时，执行完整定位与转写兼容流程，并记录“完整两段回退”。（对应 F8、F11、N6）
- AC7：计算题被可靠判断为空白时不调用额外转写，保存空白证据并维持原有判分和复核行为。（对应 F9、F11）
- AC8：跨页多批次计算题的每个批次输出、用量、定位和转写均可追溯；全部批次正常时不存在追加的全题转写请求。（对应 F10、N3、N5）
- AC9：低置信度、缺少证据或模型输出冲突仍产生现有待复核状态，不能因为使用快速路径而自动通过。（对应 F6、N4）
- AC10：全局模型并发限制小于 3 时，实际请求并发不超过该限制；限制大于等于 3 时，单份答卷仍不超过 3 道题。（对应 F12、N6）
- AC11：代表性 15 题模拟用例在相同单次调用延迟下，题目识别墙钟时间显著低于串行基线；3 道单批次计算题均走快速路径时，模型请求总数比现状减少 3 次。（对应 F1、F5、N5）
- AC12：选择题、填空题、计算题定位、学生处理、自动批改及历史版本相关测试全部通过。（对应 N7、N8）
