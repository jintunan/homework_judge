# 计算题学生作答自动定位 Spec

## 背景

教师确认的计算题题框主要用于定位题目，通常只包含题号、题干和图表，
不保证覆盖学生实际书写区域。现有流程把题框当作识别边界，导致框外或跨页的
演算过程无法进入批改证据。

## 目标

- 教师题框只作为计算题定位锚点。
- 视觉 Agent 在当前计算题与下一道已确认题目之间自动定位学生新增的作答内容。
- 搜索允许跨页，直到下一题题框；最后一题搜索至学生答卷末尾。
- 定位结果作为可追溯的批改证据，避免混入下一题作答。
- 不改变选择题和填空题现有识别方式。

## 功能需求

- F1：系统按教师确认的题目顺序建立计算题搜索窗口，从当前题题框开始，
  到下一题题框之前结束。
- F2：搜索窗口允许覆盖当前页、连续中间页及下一页；最后一道题延伸到
  学生答卷末尾。
- F3：视觉 Agent 同时查看空白模板与对齐后的学生页面，只定位学生新增的
  手写、公式、图示和演算内容，不复制印刷题干。
- F4：视觉 Agent 可返回一个或多个作答区域；系统按页码和阅读顺序保存，
  并将对应图像与转写结果交给计算题批改 Agent。
- F5：视觉 Agent 返回的区域必须位于本题搜索窗口内，不得覆盖下一题题框
  或下一题作答。
- F6：若没有发现作答且判断可靠，记录为空白作答；若边界、归属或字迹
  不确定，转为教师复核，不能擅自判空。
- F7：跨页定位、区域坐标、置信度、异常原因和所用模型均需保留，保证
  批改结果可以追溯。
- F8：重新处理学生答卷时重新执行定位，不修改教师已确认的题框。
- F9：选择题、填空题及其现有答题区逻辑保持不变。

## 非功能需求

- N1：定位失败、模型超时或结果越界时必须安全降级为“需要复核”，不能把
  缺失证据当作错误答案。
- N2：搜索窗口较长时应分批处理并合并结果，不能因单次模型输入限制截断
  跨页作答。
- N3：区域坐标必须经过确定性校验、裁剪和去重；视觉 Agent 无权扩大到
  下一题范围。
- N4：每个批改证据必须能追溯到原学生页面、原始坐标、题框版本和定位
  模型版本。
- N5：不得把整份学生答卷无差别发送给单道题的 Agent，只提供该题允许的
  搜索窗口。
- N6：保持现有数据库数据和已完成批改记录可读取；新处理批次使用新的
  定位规则。
- N7：新增逻辑应能通过模拟模型输出进行自动化测试，不依赖真实外部模型调用。
- N8：正常题框内作答不应因新定位步骤明显降低识别准确率。

## 不做的事情

- 不自动修改、扩大或覆盖教师确认的题框。
- 不要求教师额外手动画出计算题作答区域。
- 不搜索当前题锚点之前或下一题题框之后的内容。
- 不把整份学生答卷直接交给单道计算题批改 Agent。
- 不让 Agent 根据标准答案猜测学生未写出的步骤。
- 不改变选择题、填空题的答题区识别和批改规则。
- 不自动重新批改已经完成的历史批次；教师主动重新处理后才应用新规则。
- 不在本轮新增模型选择、定位参数或搜索范围的前端设置界面。

## 验收标准

- AC1：教师题框只包含计算题题干、学生在题框下方作答时，系统能定位完整
  演算区域并用于批改。
- AC2：学生解答延续到下一页或连续多页时，系统能按阅读顺序合并所有作答区域。
- AC3：下一道题与计算题位于同页或后续页面时，搜索在下一题题框前停止，
  不采集下一题作答。
- AC4：一题存在多个分散作答区域时，每个区域均被保存，并按页码与阅读顺序
  提供给批改 Agent。
- AC5：搜索窗口内只有印刷内容且确认无学生书写时，系统记录为空白作答。
- AC6：作答归属、字迹或边界不确定时，结果进入教师复核，并保留明确原因，
  不直接按空白或错误计分。
- AC7：模型返回越界、重叠下一题或重复区域时，系统拒绝或修正规则不允许的
  区域，并触发复核。
- AC8：模型超时、返回格式错误或部分页面处理失败时，任务安全降级，不产生
  无证据的确定性分数。
- AC9：批改证据可追溯到学生页面、原始坐标、教师题框版本、定位模型版本
  和置信度。
- AC10：重新处理同一学生答卷会重新定位作答，但不会修改教师题框。
- AC11：选择题和填空题的现有自动化测试及行为保持不变。
- AC12：计算题答案原本就在教师题框内时，仍能被正常定位和批改。
- AC13：长跨页窗口经过分批处理后，不丢失首尾页面的作答区域，也不越过
  下一题边界。
