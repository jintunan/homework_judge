# 计算题学生作答自动定位 Checklist

> 每项必须通过可运行测试、数据库查询或真实可观察行为验证；未执行的项目不得
> 标记为通过。

## 搜索窗口与题目边界

- [x] 教师题框仅含题干、学生在框下方书写时，定位证据超出题框并完整覆盖演算。
  （验证：同页框外流水线测试；AC1）
- [x] 当前题与下一题同页时，搜索片段止于下一题锚点顶部，下一题手写不进入候选。
  （验证：像素标记 + evidence bbox 断言；AC3）
- [x] 当前题跨一页或多页时，所有页按自然阅读顺序进入定位和最终证据。
  （验证：跨页参数化测试；AC2）
- [x] 最后一题的搜索范围延伸到学生答卷实际上传末页；尾页未配对/未对齐时不静默
  截断，而是标记证据结构不完整并复核。（验证：末页完整/缺对齐流水线测试；F2）
- [x] 锚点倒序、题框重叠、缺页或缺失对齐时不猜测边界，返回稳定复核问题。
  （验证：纯窗口测试和流水线 blocker 测试；AC7、AC8）
- [x] 当前题全部确认片段均完整落在搜索窗口；同页多栏无法用纵向半开区间表达时
  返回稳定歧义问题。（验证：多片段/多栏参数化测试；F1、AC7）
- [x] 下一题恰在后续页顶部时不生成零高度终止片段，并保留此前正高度片段。
  （验证：页顶锚点边界测试；AC2、AC3）
- [x] 重新处理同一答卷生成新定位结果，但确认题框坐标和版本保持不变。
  （验证：处理前后数据库快照；AC10）

## 视觉 Agent 定位契约

- [x] 每个模型批次只包含该题允许窗口内的模板/学生配对裁剪，不包含整份答卷。
  （验证：fake client 捕获图片尺寸、数量和片段键；N5）
- [x] 定位请求不包含标准答案、同义答案、分值、评分点或教师判定。
  （验证：请求文本敏感哨兵断言；F3）
- [x] 模型可以返回同页或跨页多个候选，系统按页码、上边界、左边界稳定排序。
  （验证：候选乱序输入测试；AC4）
- [x] 每个输入 `fragmentKey` 必须且只能返回一次；缺键、重键和未知键均进入复核。
  （验证：严格 keyed 输出参数化测试；AC6、AC8）
- [x] 根、窗口和区域三层字段集合必须精确匹配契约；额外字段、`isBlank`、Markdown
  包裹及 JSON 尾随文本均被拒绝。（验证：严格解析参数化测试；AC7、N3）
- [x] 未知片段、越界坐标、NaN、零面积和格式错误候选被拒绝并触发复核。
  （验证：定位契约参数化测试；AC7）
- [x] 高重叠重复候选不会生成重复 evidence，并保留重复问题供审计。
  （验证：候选去重测试；N3）
- [x] 题框内已有学生作答时仍能被定位，准确路径不因扩大搜索而丢失。
  （验证：框内作答回归；AC12）

## 分批、空白与失败降级

- [x] 超过 `answer_pages_per_batch` 的长窗口被完整分批，首尾页候选均被合并。
  （验证：调用批次和最终 evidence 集合；AC13、N2）
- [x] 全部批次成功、明确为空且置信度达标时，保存可靠空白并跳过转写。
  （验证：转写调用计数为 0；AC5）
- [x] 可靠空白把每个已检查窗口保存为负证据，并在定位快照标明证据种类。
  （验证：响应区域与 localization JSON；AC5、AC9）
- [x] 低置信空白、无候选但非空白、候选归属不清均进入教师复核而不直接判空。
  （验证：状态和问题代码断言；AC6、F6）
- [x] 单批超时或失败时继续处理其他批次，保留已有证据且整体状态为复核。
  （验证：部分失败 fake service；AC8）
- [x] 定位失败且无可靠空白、无证据时，批改路由不调用计算题判分模型。
  （验证：抛错 fake grading client；AC8）
- [x] 缺页、未对齐尾页、缺批或解析失败与“证据完整但低置信”分开记录；前者不调用
  正常判分模型，全部评分点为 `unable`，不得出现 `failed` 或确定性错误位置。
  （验证：结构完整性参数化测试；AC6、AC8、N1）
- [x] 定位、对齐或转写任一低置信时，最终计算题结果保留复核状态。
  （验证：组合置信度参数化测试；AC6）
- [x] 最终候选的裁剪 padding 始终限制在父搜索窗口内，不读取下一题像素。
  （验证：候选紧贴终止边界的像素测试；AC3、AC7）
- [x] 跨页下一题位于终止页中部时，窗口下边界精确等于下一题顶部，边界及以下
  标记像素均不进入定位或批改图。（验证：跨页像素测试；AC3、F5）

## 证据、持久化与审计

- [x] 每个定位候选生成唯一 evidence ID，并保存学生原页像素坐标。
  （验证：`student_response_regions` 查询；AC4、AC9）
- [x] `raw_recognition_json.localization` 保存搜索窗口、下一题边界、批次状态、
  `schemaVersion: 1`、`batchIndex/attemptId`、定位模型 ID、提示词版本、原始输出、
  用量、置信度和问题；未知版本只读降级。（验证：JSON 快照断言；AC9、F7）
- [x] 持久化搜索计划是去除运行时模板/学生图像字段的 snapshot DTO，任何图像 bytes
  均不进入 localization。（验证：序列化字段集合测试；N4、N5）
- [x] 模型片段 0..1000、模板归一化、模板像素和学生原页像素 bbox/polygon 坐标
  单位明确且换算正确。（验证：透视/缩放坐标参数化测试；AC9、N3、N4）
- [x] localization 的全部 evidence ID 集合与该响应全部区域 ID 完全相等，包括定位
  候选和 `blank_search_window` 负证据。（验证：CAS 提交校验；AC5、AC9）
- [x] 每条映射带 `batchIndex/attemptId/modelCandidateIndex`，多批次和重试中的模型
  候选可唯一追溯。（验证：重复候选序号审计测试；AC9）
- [x] 可从历史 `grading_question_results.student_response_id` 与 evidence region ID
  反查定位快照、处理/题框版本、响应区域和学生页。（验证：完整跨表查询；AC9）
- [x] 历史学生响应和历史批改记录无需迁移即可继续读取。
  （验证：现有数据库迁移与 API 回归；N6）
- [x] 重新处理只写入新的处理版本，不覆盖旧版本的定位快照和证据。
  （验证：双版本数据库查询；F8）

## 计算题批改 Agent 证据输入

- [x] 批改流水线重放该响应捕获的 alignment revision，把学生原页变换到模板坐标系，
  按精确模板 bbox 临时裁剪模板/学生配对图；禁止直接用原页轴对齐 bbox 裁批改图。
  （验证：带透视页面像素测试；F4、F5、N4）
- [x] 每个正证据和 `blank_search_window` 负证据都按相同顺序发送 evidence ID、
  转写（空白为 empty）及对应模板/学生配对图。（验证：fake grading client 捕获
  多模态 user content；F4、AC5）
- [x] 批改 Agent 不能引用当前响应之外的 evidence ID。
  （验证：非法模型输出测试；F5）
- [x] 任一正证据或空白负证据的模板/学生图缺失时不降级为纯文本确定性判分：
  不调用模型，全部评分点 `unable`，无 `failed` 或确定性错误位置。
  （验证：正/负证据缺图故障注入；AC8、N1）
- [x] 结构性不完整分支中的数值 0 仅作现有存储契约占位，始终携带
  `needs_review/MISSING_EVIDENCE`，且不作为确定分展示、汇总或导出。
  （验证：持久化、序列化和汇总边界测试；AC8、N1）
- [x] 图像 bytes 不进入评分快照、原始识别 JSON 或数据库。
  （验证：快照和数据库内容扫描；N4、N5）

## 端到端场景

- [x] 场景 A：教师框只含计算题题干 → 学生在框下同页演算 → 视觉 Agent 定位
  实际书写 → 转写 → 批改 Agent 同时收到该 evidence 图像和转写并完成评分。
  （AC1、AC4）
- [x] 场景 B：学生答案从当前页延续两页 → 系统分批定位并合并 → 下一题锚点前
  停止 → 下一题作答未混入。（AC2、AC3、AC13）
- [x] 场景 C：窗口内无学生书写 → 所有批次高置信空白 → 保存实际检查窗口的负证据
  → 批改 Agent 收到空转写和模板/学生配对图后进入正常批改，不伪造作答候选。
  （AC5）
- [x] 场景 D：跨页中间批次模型失败 → 其余页证据仍保存 → 本题显示明确复核原因 →
  不调用正常判分模型且全部评分点 `unable`，不产生无证据确定性判分。（AC6、AC8）
- [x] 场景 E：教师主动重新处理答卷 → 新处理版本重新定位 → 原题框和历史批改结果
  不变。（AC10）
