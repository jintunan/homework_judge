# 派生填空配置与正式批改状态一致性 Checklist

> **已被部分取代（2026-08-09）：** 本文中“区域冲突不阻断”“只有总分时自动均分”“开始批改时静默生成或确认配置”等旧规则，已由 [题框驱动的逐空识别与模型批改 Spec](../2026-08-09-question-frame-blank-grading-pipeline/spec.md) 取代。本文仅保留历史记录；新流程要求 B1…Bn 的题面空位、独立锚点、标准答案和显式逐空分值严格一致。

> 本清单只验证本次独立缺陷修复。自动确认必须由确认题目、完成任务或启动评分触发；普通 GET 始终只读，已有教师配置始终优先。

## 根因复现与安全判定

- [x] 未保存的安全三空题 GET 返回三个完整空位、`source=derived` 和 `autoConfirmable=true`。（验证：评分配置 API 测试；AC1）
- [x] 同一题连续 GET 两次，配置头、空位和审计表行数均不增加。（验证：GET 前后数据库计数；AC1）
- [x] 三空中任一标准答案为空时 `autoConfirmable=false`，blockingReasons 包含稳定空答案原因。（验证：纯规则参数化测试；F1）
- [x] 空位分值小于等于零或分值和不等于题目满分时不可自动确认。（验证：Decimal 分值边界测试；F1）
- [x] 复合区域共享、区域缺失或区域数量冲突只保留 advisory warning，不阻断答案和分值完整的候选。（验证：第 9—12 题形态回归；AC2）
- [x] 无法安全拆分答案时包含 `answer_split_ambiguous`，所有空位标准答案为空且不可自动确认。（验证：初始化与就绪组合测试；AC3）

- [x] 确认阻断时题目及匹配保持调用前状态，配置头、空位和审计均不新增。（验证：失败前后状态对比；N3）

## 任务完成事务

- [x] 任务有多个安全未保存填空题时，完成动作在同一事务中保存全部配置并更新任务为 completed。（验证：多题完成集成测试；F5）
- [x] 两道安全题加一道歧义题时，完成失败且本批三题都不产生配置头、空位或自动确认审计。（验证：全有或全无测试；AC4）
- [x] 修正歧义题后再次完成，三题配置和任务完成状态一次提交。（验证：失败—修正—成功测试；AC4）
- [ ] 任务完成阻断消息一次列出所有需要处理的填空题号，不只报告第一题。（验证：多 blocker 错误详情；F4）
- [ ] 孤立答案、题目未确认等原有 blocker 与填空 blocker 能同时阻止完成，不提前保存候选配置。（验证：组合 blocker 测试；F5）

## 历史任务评分启动

- [x] 构造“任务已完成、题目已确认、配置为空”的历史安全三空题，创建评分运行时自动保存配置并返回 202。（验证：评分 API 历史任务测试；AC2）
- [x] 自动补齐后的评分输入快照包含 B1-B3、逐空答案和守恒分值，不再触发 `FILL_BLANK_CONFIG_REQUIRED`。（验证：评分运行快照断言；AC2）
- [x] 历史任务包含歧义填空题时不创建评分运行，错误详情包含全部问题题号和原因代码。（验证：评分启动阻断测试；AC3）
- [x] 评分启动的配置批次有任一 blocker 时，其他安全候选也不产生部分保存。（验证：评分预检事务计数；N3）
- [x] 重复评分预检或后台再次构建输入不会增加配置版本、空位或自动确认审计。（验证：重复调用计数；AC5）
- [x] 已有教师配置在评分启动后逐字段不变，评分输入继续使用教师保存值。（验证：配置快照前后比较；N2）
