# 学生试卷整题区域展示与任务删除 Spec

> **已被部分取代（2026-08-09）：** 本文关于学生侧自动补算/扩张题框、缺页时继续识别、以答案框或外接框代表整题范围的规则，已由 [题框驱动的逐空识别与模型批改 Spec](../2026-08-09-question-frame-blank-grading-pipeline/spec.md) 取代。本文仅保留历史决策记录；新实现必须使用教师确认的完整题框集并对整批映射失败关闭。

## 背景

系统已经能够把固定版式的学生试卷与空白试卷逐页对齐，识别每题的学生作答，并保存学生原始页面及作答区域在原页上的坐标。当前仍缺少整道题的区域数据和面向教师的可视化页面，因此无法像参考产品一样，在学生原图上直接查看题目分割结果。

任务列表当前也缺少删除入口。无用、失败或测试任务会长期保留对应数据库记录和上传文件，教师无法自行清理。

## 目标

- 从空白试卷模板获得覆盖题干、选项和作答位置的完整题目区域。
- 将模板题目区域映射到学生原始页面，并持久保存原页坐标。
- 在前端以学生原始页面为底图，叠加显示题目边框和题号。
- 为任务提供带二次确认的永久删除能力，并确保后台处理先停止、任务数据和文件被完整清理。

## 功能需求

- F1：系统必须在识别空白试卷时，为每道题识别完整题目区域。区域应覆盖该题题干、全部选项、插图以及题目预留的作答位置，不得只返回学生作答框。
- F2：一道题在同一页存在多个不连续区域或跨越多页时，系统必须保存多个有顺序的区域片段；每个片段必须标明所属模板页。
- F3：模板题目区域必须使用相对于模板页面的坐标保存。处理学生试卷时，系统必须通过对应页面的对齐关系，把每个区域映射为学生原始页面上的像素坐标；持久化结果必须引用原始学生页面，不得以裁剪图代替原页坐标。
- F4：历史任务尚无完整题目区域时，系统必须能够基于已保存的空白试卷页面补充识别并缓存区域。无法可靠识别的题目必须明确标记为缺少区域或需要检查，不得静默生成猜测框。
- F5：教师必须能够从任务进入学生试卷页面，查看学生提交列表并选择一份试卷。学生试卷尚在处理时，页面必须显示当前状态并自动刷新；处理失败时必须显示原因和可重试入口。
- F6：学生试卷详情必须逐页显示学生原始页面，并按原页坐标叠加整题边框。每个区域显示题号标签；同一题的多个区域使用一致标识。页面缩放或容器尺寸变化时，题框必须与原图同步缩放并保持位置一致。
- F7：题框样式必须用于表达题目分割和当前选中状态，不得使用颜色暗示答题正确或错误。区域缺失、对齐质量不足或需要人工检查时，页面必须提供文字提示。
- F8：任务列表中的每个任务必须提供删除选项。执行删除前，前端必须弹出二次确认，明确提示空白卷、参考答案、学生试卷、识别结果和页面图片都将永久删除；取消确认不得产生任何修改。
- F9：确认永久删除后，系统必须先停止该任务及其学生试卷的所有后台处理，再删除任务关联的数据库记录和任务目录文件。成功响应后任务不得继续出现在列表中，也不得留下仍在写入该任务的后台作业。
- F10：删除不存在的任务、重复提交删除请求或删除过程中发生失败时，系统必须返回明确结果；不得误删其他任务的数据或数据根目录之外的文件。

## 非功能需求

- N1：题框坐标映射必须以学生原始页面尺寸为基准，不受浏览器显示尺寸、设备像素比或页面缩放影响。
- N2：在桌面版 Chrome 和 Edge 的 1280×720 及以上窗口中，学生原图、题框、页码切换和学生提交导航必须可操作；长页面允许滚动查看。
- N3：叠加层不得修改、压缩或覆盖学生原始页面文件；浏览器只读取受控的学生页面接口。
- N4：删除接口必须校验任务标识并限制文件清理范围。只有目标任务目录可以被删除，数据库级联不得影响其他任务。
- N5：区域解析、坐标映射、学生详情接口、任务删除和主要前端交互必须有自动化测试；现有后端、前端和类型检查不得回归。

## 本次不做

- 不判断学生答案正确或错误，不计算得分，也不在原图上显示对勾、叉号或评分颜色。
- 不生成批改评语、知识点分析、班级统计或成绩报表。
- 不提供题目区域的拖拽、缩放、拆分或合并编辑器；区域修正留给后续功能。
- 不实现任务回收站、恢复、归档或软删除；本次删除为二次确认后的永久删除。
- 不改变固定版式逐页对齐策略，也不支持学生试卷页数与模板页数不一致时的自动重排。
- 不把裁剪后的题目图片作为唯一证据保存。

## 验收标准

- AC1：对包含选择题的空白卷执行识别后，每道题都至少产生一个完整题目区域，边框覆盖题干、全部选项和作答位置，而不是只覆盖学生填写处。（F1）
- AC2：同一题跨页或包含多个不连续片段时，接口返回带页面归属和顺序的多个区域；前端在对应学生原页上分别显示这些区域，并使用相同题号。（F2、F6）
- AC3：对齐一份学生试卷后，数据库保存模板相对坐标和学生原页像素坐标。删除临时裁剪结果或刷新浏览器后，题框仍能根据原始页面和原页坐标准确显示。（F3、N1、N3）
- AC4：打开没有历史整题区域的旧任务时，系统从已保存模板补充区域并在后续访问中复用；某题无法可靠定位时，页面显示该题区域缺失或需要检查，而不是显示虚假框。（F4、F7）
- AC5：教师从任务进入学生试卷页面，可选择学生提交并逐页查看原图。调整窗口宽度或缩放显示后，题框四边仍与同一题内容保持重合，题号标签清晰可见。（F5、F6、N2）
- AC6：学生试卷处理中时页面自动刷新状态；失败时显示错误信息和重试入口；低质量对齐使用文字状态提示，不使用对错颜色。（F5、F7）
- AC7：点击任务删除选项后首先出现永久删除确认；选择取消时任务、文件和学生提交均保持不变。（F8）
- AC8：确认删除一个正在处理的任务后，其任务级和学生试卷后台作业先停止；删除成功后，任务从列表消失，详情接口不可再访问，目标任务的上传文件和页面图片被清理，其他任务保持不变。（F9、N4）
- AC9：对不存在的任务执行删除得到明确的未找到结果；重复删除不会清理其他目录。模拟文件清理或后台停止失败时，接口返回可理解的失败信息，不报告虚假成功。（F10、N4）
- AC10：新增自动化测试、现有后端测试、前端交互测试、代码规范和类型检查全部通过。（N5）
