# 题框驱动的逐空识别与模型批改 Spec

## 背景

系统当前同时保存“完整题目区域”“作答证据区域”和“填空空位”，但三者之间缺少强约束。模型产生的非空区域会直接进入后续流程，即使题框没有覆盖完整选项、答题区域把多个空合并在一起，或者区域数量与空位数量不一致，也可能被标记为可用。

真实样本已经暴露出两类连锁问题：某道三空题中，系统得到一个覆盖三个空的复合区域和一个误落在选项上的区域；识别模型随后把三个答案分配成两个区域段，评分输入再按段序号绑定 B1、B2、B3，最终产生答案错位。另一些题目的题框只覆盖题干或部分选项，上传学生试卷后即使页面对齐成功，也只能把这个不完整模板框映射到学生原页。第 8 题和第 11 题只是用于复现这两类问题的真实回归样本，不定义产品规则。

本次改造把完整题框提升为整个识别与批改流程的上游事实来源，并明确区分三种对象：完整题框用于划分整道题，空位用于标识题内每个待答位置，证据用于记录学生原页上支持某个识别结果或判定的区域。任何阶段都不得再把“一个图像区域”等同于“一个空”。

## 目标

- 在空白模板上由模型自动初划每道题的完整题框，并由教师逐题检查、修正和确认；全部有效题框确认前，不允许上传或处理学生试卷。
- 学生试卷只根据已确认模板题框和页面配准关系进行坐标映射，不再为每份学生试卷重新猜测题目边界；低质量、越界或相互冲突的映射必须阻断该份答卷并进入校正流程。
- 在已确认题框内部识别填空数量并尽可能定位空位，将参考答案配置到连续的 B1、B2……；空位身份、逐空标准答案和逐空分值必须严格一致，空位锚点仅作可选定位提示，缺失时由完整题框提供共享识别上下文。
- 采用两阶段模型流程：第一阶段在看不到标准答案的条件下，按 blankKey 提取学生逐空答案；第二阶段读取逐空答案和已确认标准答案，逐空给出结构化判定。最终分值由后端根据已确认分值配置确定性汇总。
- 废止区域段序号与空位序号直接绑定、区域冲突仍自动放行、以及通过模型自报置信度认定题框完整的现有行为。
- 使题框、空位、识别答案、判定和原页证据都可追踪、可复核，并能准确指出阻断发生在哪一层。

## 术语与边界

- **完整题框**：空白模板上覆盖一道题全部内容的一个或多个区域片段，包括题干、所有小问、图表和选项。跨页题允许有多个片段，但它们共同属于同一道题。
- **空位**：填空题中一个独立作答单元，使用连续且稳定的 `B1`、`B2`……标识。空位是语义对象，不以图像裁剪块的数量定义。
- **空位锚点**：模板上用于提示某个空大致位置的区域。锚点可缺失或与其他锚点共享视觉上下文，但不能因此合并空位。
- **映射题框**：通过模板页到学生页的几何配准，将已确认完整题框投影到学生原页得到的区域。
- **识别证据**：学生原页上支持逐空转写结果的区域引用。证据可以被多个空共享，不等同于完整题框或空位。
- **标准答案**：教师确认的逐空参考答案和可接受变体。识别阶段不得读取标准答案，判分阶段才可读取。
- **有效题目**：未标记为重复、作废或明确排除处理的题目。门禁只统计有效题目，但排除动作本身必须可审计。

当完整题框、空位、证据三类区域发生冲突时，以教师确认的完整题框作为页面范围事实，以教师确认的空位定义作为答案身份事实；模型输出只能形成草稿、建议或待复核结果，不能覆盖这两类事实。

## 功能需求

- **F1：对象分层与稳定身份。** 系统必须分别保存完整题框、空位/空位锚点、学生逐空答案、逐空判定和识别证据，并使用题目 ID、题框版本和 `blankKey` 建立关联。任何流程不得再用“区域数组下标”推断 `blankKey`。
- **F2：完整题框自动初划。** 空白模板识别完成后，系统必须为每道有效题目生成完整题框草稿。草稿应覆盖题干、所有小问、图表和声明的选项/答题区，同时排除前后题、页眉页脚和无关邻近分区；跨页题可产生多个有序片段。模型置信度仅供排序和提示，不得代表教师确认。
- **F3：教师逐题确认题框。** 复核页必须在原始模板页上显示题框草稿，并允许教师选择题目、拖动、缩放、重画、增加或删除片段，然后逐题确认。确认前必须校验页码、范围、正面积、片段归属以及不可接受的跨题重叠；教师确认表示其已人工检查题目内容完整性。
- **F4：题框前置门禁。** 只有全部有效题目的完整题框均处于已确认状态，任务才允许上传或处理学生试卷。接口和界面必须执行同一门禁；绕过界面的请求也要返回明确的阻断原因和未确认题目列表。
- **F5：版本与失效传播。** 教师修改已确认题框、题目类型或影响空位结构的题目内容后，系统必须生成新版本并使依赖旧版本的空位配置、学生映射、逐空识别和判分结果标记为过期。旧结果保留用于审计，但不得继续作为当前结果使用；重新确认后才能按依赖顺序重处理。
- **F6：模板到学生页的唯一定位路径。** 学生试卷的题目范围只能由已确认模板题框通过页面配准映射得到，不得为每份学生试卷调用模型重新猜测题目边界。系统必须记录所用模板题框版本、页面配准版本和映射结果。
- **F7：映射质量阻断与校正。** 当映射缺页、越界、严重裁切、与其他题冲突或配准质量低于可用标准时，该份学生答卷必须停在待校正状态，不得进入答案识别。教师应能在学生原页上修正页面对应关系或页面级配准控制点，系统随后重新计算全部受影响题框；不允许通过单独移动某一道学生题框来掩盖错误配准。
- **F8：题框内逐空检测。** 对填空题，系统必须只在已确认完整题框内检测实际空位，按页面和阅读顺序生成连续的 `B1`、`B2`……，并在定位可靠时附带锚点。检测结果必须给出可复核的数量、可选位置和问题提示，且不得把选择题选项标记或一个覆盖多个空的复合区域当成额外空位；定位不可靠时允许该空 `region=null`，由完整题框作为共享识别范围。
- **F9：标准答案与分值自动配置及严格确认。** 系统必须把标准答案解析成逐空答案并与检测到的空位逐一配置。单题题框项已由教师确认，且题面空位数量与逐空答案数量一致、键集合完整连续、题目总分有效时，系统按最小计分精度确定性分配逐空分值，保证总和严格等于题目满分，并自动建立已确认配置版本；不要求等待整套题框冻结，也不要求教师逐空保存。整套题框仍须冻结后才能处理学生卷。余数按稳定的空位顺序分配，结果可由教师后续覆盖。缺失/共享锚点只形成 advisory；已提供但非法或位于确认题框之外的锚点仍是 blocker。空数或答案冲突、重复键、无效总分及教师显式配置的分值冲突必须阻断。
- **F10：无答案泄漏的逐空识别。** 第一阶段模型只接收学生完整题框图像、题目上下文、预期 `blankKey` 列表和可用空位锚点，不得接收标准答案或判分结论。模型必须按键返回每个空的转写、是否留空、置信信息、问题提示和证据引用。缺键、重复键、多余键、格式错误或无法可靠区分多个空时，系统必须重试或转教师复核，不得按换行、区域顺序或猜测补齐。
- **F11：逐空模型判分。** 第二阶段在逐空识别通过结构校验后，读取已确认的学生逐空答案、标准答案、评分规则和题目上下文，按 `blankKey` 给出结构化判定、理由、置信信息和复核标记。模型不得改变空位身份、标准答案、单空满分或总分；模型无法判断、识别置信不足以及工具校验与模型结论冲突时，必须进入教师复核。
- **F12：确定性汇总。** 后端必须验证判分结果的键集合、取值范围和版本一致性，再根据已确认的逐空满分与判定确定性计算题目得分。总分不得取自模型自由文本或模型自行相加的数值。空位级结果、汇总过程和教师覆盖均须保存审计信息。
- **F13：分层可视化与复核。** 模板复核页、学生映射页和批改页必须以不同样式和图例区分完整题框、空位锚点与识别证据。批改页默认展示完整题目范围，可切换查看空位和证据；界面不得把证据框标注成“题框”。每个阻断状态必须显示发生层级、问题代码和可执行的下一步。
- **F14：历史任务兼容。** 现有任务和学生答卷不得被静默认定为满足新门禁。历史题框、空位配置和识别结果应标为待确认或旧版本；教师确认完整题框和空位配置后，系统才按新流程重建映射、识别与判分。原始文件和旧结果必须保留。
- **F15：通用处理而非样本特判。** 同一流程必须适用于任意有效题号、学科文本、标准答案内容、正整数空位数量和常见排版，包括单空/多空、同一行/跨行、多个小问、相邻选项或图表、一个证据区域支持多个空以及跨页题框片段。业务行为只能由当前题框集、题目结构、已确认空位配置和运行时模型结果驱动；不得按第 8/11 题题号、固定答案、固定坐标、文件哈希或测试夹具名称编写生产逻辑。

## 非功能需求

- **N1：坐标一致性。** 模板区域使用带页码的归一化坐标保存，学生映射同时保留原页多边形和可见外接框；所有转换必须可重复，并在不同渲染尺寸下保持一致。
- **N2：失败关闭。** 题框、空位身份/答案/分值、配准、逐空识别或判分任一层出现结构性错误时，默认阻断下游，不允许以模型高置信度、非空结果或旧缓存自动放行。可选锚点缺失不是结构性错误；已提供但几何非法的锚点仍失败关闭。
- **N3：答案隔离。** 识别阶段的请求、日志和持久化快照不得包含标准答案；判分阶段必须使用识别阶段已经落库并通过校验的结果，禁止在同一次模型调用中边看标准答案边转写学生答案。
- **N4：可审计与幂等。** 自动生成、教师编辑、确认、失效、重跑和教师改判都必须记录操作者、时间、版本、原因和前后摘要。相同版本的重复请求不得生成互相矛盾的当前结果。
- **N5：并发安全。** 教师保存题框或配置时必须带预期版本；并发编辑冲突应提示刷新，不得后写覆盖先写。后台作业提交结果前必须再次检查依赖版本，旧作业不得覆盖新版本。
- **N6：可用性与性能。** 题框编辑和页面切换应使用本地叠加渲染，不因拖动频繁调用模型；一份学生答卷的题框映射应在一次页面配准后批量完成。模型调用失败应有有限重试、明确超时和可恢复状态。
- **N7：可测试性。** 几何校验、版本失效、三方一致性、严格键校验和确定性计分必须有无需真实模型的单元测试；模型边界通过固定响应夹具测试。测试必须先用参数化通用样例覆盖不同题号、1/2/3/5 个空、同/跨行、复合证据和选项干扰，再用真实第 8/11 题作为额外回归样例。

## 不做的事

- 不让模型替代教师完成完整题框的最终确认。
- 不为每份学生试卷重新识别题号或猜测独立题目边界；学生侧只做页面配准、映射和必要的页面级校正。
- 不用标准答案反向引导学生手写内容识别，也不在第一阶段判断正误。
- 不把本次改造扩展为通用图像标注平台；本周期不新增教师手工绘制空位锚点，编辑能力覆盖题框片段和学生页面配准校正，空位锚点仅由可靠检测结果可选提供。
- 不在本周期重做选择题、判断题或计算题的全部评分语义；它们复用已确认完整题框和映射门禁，逐空配置与逐空判分只适用于填空题。
- 不猜测缺失或含糊的标准答案及可接受变体；逐空分值仅在总分和空数明确时按公开、确定性的等额规则分配，教师可覆盖。
- 不删除历史原图、模型原始响应或旧判定，也不自动批量确认历史任务。
- 不以字符级 OCR 框替代题框、空位或证据的业务对象。
- 不为第 8 题、第 11 题或任何单份试卷写题号、答案、坐标、页码或文件级特判；真实样本只能出现在测试夹具和验收证据中。

## 验收标准

- **AC1（F1）**：检查任一填空题的数据与接口，可分别找到题框版本、`B1...Bn` 空位、逐空识别、逐空判定和证据引用；交换或增删证据区域不会改变 `blankKey`。
- **AC2（F2、F3）**：新模板识别后每道有效题均有可见草稿；教师可在原页完成片段增删、拖动、缩放或重画，并且只有通过几何校验的题框可逐题确认。
- **AC3（F4）**：存在任一未确认题框时，界面禁用学生上传/处理，直接调用接口也返回阻断代码及题号；全部题框确认后同一操作立即可用。
- **AC4（F5）**：确认后修改某题题框会提升版本，并将该题的空位配置及既有学生映射、识别和判分标为过期；旧后台作业完成也不能覆盖新版本数据。
- **AC5（F6、F7）**：学生页不触发独立题框识别；正常配准可批量得到与模板版本对应的题框。制造缺页、越界或冲突后流程停在待校正，修正页面配准后重新映射并继续。
- **AC6（F8）**：对任意配置为正整数 `n` 个空的填空题，系统在确认题框内生成且仅生成连续键 `B1...Bn`，不因多个空共享一块视觉上下文而合并，也不把选项标记、图中文字或题框外内容当作空位。参数化测试至少覆盖 1、2、3、5 个空、同一行、跨行和多个小问；真实第 11 题作为三空回归样本，结果为 B1“电荷转移”、B2“遵守”、B3“CD”。
- **AC7（F9）**：对任意 `n`，单题题框项已确认、题面空位与逐空答案均为 `n`、键集合一致且总分有效时，系统自动生成总和精确守恒的逐空分值并确认配置；题框集仍为草稿不构成该单题自动配置的 blocker，但学生处理继续受整套冻结门禁约束。零个、少于 `n` 个或共享的锚点只显示 advisory。已提供但越界/非法的锚点、空数/答案不一致、缺失答案或无效总分仍显示具体 blocker。教师显式修改分值后以教师版本为准，不被自动配置覆盖。
- **AC8（F10）**：识别请求快照不包含标准答案；对运行时期望键集合 `K={B1...Bn}`，模型响应键集合必须精确等于 K，返回顺序不影响绑定。对任意 `n`，缺少任一键、重复任一键、增加额外键或退化为区域段时，结果进入有限重试/复核而不是错位填充；B1/B2/B3 仅是三空示例。
- **AC9（F11、F12）**：第二阶段对每个合法 `blankKey` 产生独立判定，后端拒绝缺键、多键、非法分值或旧版本结果，并根据配置得到可重复的逐空分数和题目总分。
- **AC10（F13）**：三个页面均有清晰图例；对任意题目，批改页可同时定位确认的完整题目范围、该题全部空位及对应证据，且不同层级不会使用相同标签误导教师。真实第 11 题额外验证题框覆盖全部 A-D 选项和三个空位。
- **AC11（F14）**：升级后的历史任务首次打开时显示“题框待确认/结果为旧版本”，学生处理被门禁阻断；完成确认和重处理后转入新状态，原始文件与旧结果仍可追溯。
- **AC12（F2、F6、F13）**：通用题框 oracle 以 required sentinels 表示必须覆盖的题干、小问、图表、声明选项/答题区，以 forbidden sentinels 表示必须排除的前后题、页眉页脚和邻近分区；选项数量与标签可变。真实第 8 题作为一个实例，模板框包含题干、图和 A-D 且排除相邻题，学生映射和批改页保持相同包含/排除关系，整页巨框不能通过。
- **AC13（N1-N7）**：在不同浏览器缩放下叠加位置稳定；故意制造结构错误时均失败关闭；并发保存出现版本冲突；识别请求无答案泄漏；自动化测试、类型检查、静态检查和构建全部通过。
- **AC14（F15）**：将相同参数化场景替换为不同题号、题干、答案文本、页码和坐标后，系统仍仅按输入结构得到相同关系；生产代码扫描不含第 8/11 题号、示例答案、oracle 坐标、文件哈希或 fixture 名称的条件分支。真实样本测试删除后，全部通用单元与集成测试仍能证明核心规则。
