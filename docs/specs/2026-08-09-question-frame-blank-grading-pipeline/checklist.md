## AC1：对象分层与稳定身份

- [x] 同一道填空题可分别查询 frame set/item/region、blank config/definition、student blank response、grading blank result 和 evidence reference。（验证：API/数据库集成测试逐层断言独立 ID 与版本）
- [x] 交换 evidenceRefs 顺序或让 B1/B2/B3 共享同一完整题框证据，不会改变任何 `blankKey` 或答案绑定。（验证：严格键单元测试）
- [x] `student_responses.recognized_text` 仅是展示摘要，清空或改变它不会改变填空评分输入。（验证：grading pipeline 测试仍从 keyed rows 得到相同结果）

## AC2：模型初划与教师逐题确认

- [x] 新模板识别后每道有效题都有 pending 题框项，模型置信度 1.0 也不会自动 confirmed。（验证：pipeline/service 单元测试）
- [ ] 教师能在模板原页拖动、八向缩放、重画、增加/删除片段并切换跨页片段。（验证：UI 自动化 + Chrome/Edge 人工操作）
- [x] 零面积、越界、非法页、重复键和严重跨题重叠不能保存/确认，错误指向具体题和片段。（验证：geometry/API 测试）
- [x] 保存后的被编辑题回到 pending；脏数据不能确认；全部有效题确认且全局校验通过后才能冻结 frame set。（验证：service/API/UI 状态机测试）

## AC3：题框上传与处理门禁

- [x] 只要一题缺框或未确认，上传 UI 禁用并列出题号。（验证：question-frame-review UI 测试）
- [x] 绕过 UI 直接上传时返回 `409 QUESTION_FRAMES_NOT_CONFIRMED`，且拒绝发生在文件落盘前。（验证：student submission API 测试和存储目录断言）
- [x] 学生处理重试、任务完成和其他服务端入口使用同一 gate，不能绕过。（验证：集成测试逐入口调用）
- [x] 标记为重复/排除的题不计入门禁；恢复为有效题会立刻关闭 gate。（验证：lifecycle 测试）

## AC4：版本、并发与失效传播

- [x] 冻结 frame set 不可原地修改；编辑时产生下一版本草稿，旧版本仍可查看。（验证：frame version 单元测试）
- [x] 两个相同 expectedRevision 的并发保存只有一个成功，另一个返回 409 且不覆盖数据。（验证：并发服务/API 测试）
- [x] frame set 变化后，依赖旧集的空位配置、当前学生处理、评分和产物立即显示过期/非当前。（验证：invalidation 测试和 UI 状态）
- [x] 旧 frame/config/alignment 版本的后台结果晚到时不能覆盖 current 指针，并留下 abandoned/version-changed 事件。（验证：延迟 future/CAS 测试）

## AC5：唯一映射路径与失败关闭

- [x] 学生处理期间 `recognize_question_regions()` 调用次数严格为 0；缺确认题框时直接阻断。（验证：抛错 spy 测试）
- [x] 正常配准后，一次批量映射得到 frame set 全部有效片段，并记录 frameSetId、frameRegionId、alignmentRevision 和 processingRevisionId。（验证：mapping/pipeline 测试）
- [x] 缺页、低质量、不可逆变换、退化多边形、严重裁切、越界或跨题冲突时，状态为 `mapping_needs_review` 且答案模型调用数为 0。（验证：参数化失败关闭测试）
- [x] 教师修改页面对应或四对控制点后，系统重算该页所有题框并创建新修订；不存在单题学生框自由移动接口。（验证：alignment API/UI 测试）
- [x] 学生页逐片段原样绘制服务端多边形，不与答案框合并、不取同题外接矩形、不向下一题延伸。（验证：student overlay UI 测试）

## AC6：任意空数与第 11 题回归

- [x] 对不同题号、题干和坐标的 1/2/3/5 空案例，题框内得到且仅得到连续的 B1...Bn。（验证：参数化 blank detection 测试）
- [x] 同一行、跨行、多个小问和共享视觉上下文均使用同一检测/键生成路径，不把多个语义空合并。（验证：通用排版矩阵）
- [x] 选项标记、图中文字和题框外内容不成为空位；改变选项字母或学科文本后对象关系不变。（验证：干扰项参数化负例）
- [ ] 作为额外真实回归，第 11 题完整题框覆盖题干、图和 A-D，并得到 B1“电荷转移”、B2“遵守”、B3“CD”。（验证：oracle 哨兵点 + 固定响应 + 原页人工检查）

## AC7：填空配置严格确认

- [x] 对任意正整数 `n`，题面标记数、逐空答案数和键集合一致即可满足数量/身份门禁；0/`n-1`/共享锚点不改变 `blankKey`。（验证：n=1/2/3/5 参数化测试）
- [x] `missing_blank_anchor`、仅由定位数量引起的 `answer_region_count_conflict` 和 `composite_region_shared` 只作为 advisory；无锚点配置可保存并使用完整题框共享识别。（验证：readiness/API/学生识别测试）
- [x] 已提供锚点的非法页码、非正面积、越界或题框外位置仍为 blocker；重复/缺键、缺/多答案和版本冲突仍失败关闭。（验证：readiness 单元测试与 API 响应）
- [x] 已保存一条或多条空位记录不会跳过完整性校验；只有版本 0 的安全候选可自动建立配置，已有教师/待确认版本不被覆盖。（验证：config/API 回归测试）
- [x] 没有教师逐空分值时，对任意 1/2/3/5 空按最小计分精度确定性分配，所有分值为正且总和精确等于题目满分。（验证：Decimal 参数化测试）
- [x] 安全派生配置在题目确认、任务完成、学生处理或批改入口自动写入 `auto_confirmed` 版本；已存在教师/待确认版本不被覆盖，歧义题不阻断同任务安全题落库。（验证：service/API/pipeline 测试）
- [x] 实际任务三空题从配置版本 0 自动生成 `auto_confirmed` v1，分值为 1.33/1.33/1.34，不再出现 `blank_score_missing` 或填空配置复核提示，审计 `modelCalls=0`。（验证：实际第 9 题 API）

## AC8：无答案泄漏的键控识别

- [x] 第一阶段请求和 request snapshot 递归扫描不到标准答案、同义词、正确性、逐空分值或判分字段。（验证：捕获模型请求的 spy 测试）
- [x] 对运行时 K={B1...Bn}，任意乱序返回仍按键正确保存。（验证：n=1/2/3/5 parser/service 参数化测试）
- [x] 对任意 K，缺任意键、重复任意键、增加任意额外键、非法 JSON、矛盾 isBlank 或未知证据 ID 均不会进入评分。（验证：参数化严格解析测试）
- [x] 第一次结构错误最多进行一次带错误详情的重试；再次失败进入 `recognition_needs_review`，不按换行、数组或区域下标补齐。（验证：模型调用次数和持久化状态）
- [x] 一个证据区域可显式支持多个空，一个空可引用多个证据，且关系不会由答案文本子串猜测。（验证：evidence relation 测试）

- [x] 对 1/2/3/5 空及不同分值向量，后端均通过同一聚合函数得到可重复总分。（验证：参数化 calculation 测试）

- [ ] **新任务正常路径：** 模型初划 → 教师逐题改框/确认 → 冻结题框集 → 自动/人工确认空位配置 → 上传学生卷 → 映射 → B1..Bn 识别 → 每空模型判定 → 后端汇总 → 批改页三层复核，所有状态和版本连续可追踪。（验证：API 集成测试 + 浏览器人工走查）
