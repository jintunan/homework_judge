# 前端操作闭环与复核后错题报告 Spec

## 背景

当前系统已经具备任务识别、题目确认、学生答卷处理、教师批改复核以及批注/错题报告生成能力，但部分界面操作点击后没有明显反馈，失败时也可能没有可见提示。现有自动化界面测试仅覆盖展示与局部交互，没有覆盖主要按钮的请求、成功、失败和刷新闭环。教师完成最后一项批改复核后，系统虽然设计为继续生成批注和错题报告，但必须补足端到端验证和失败恢复，确保教师实际拿到报告。

## 目标

- 让当前主要业务路径中的可操作按钮在点击后都有明确、可观察的结果。
- 让禁用按钮说明不可操作的原因，避免看起来“没有反应”。
- 在教师解决最后一项批改复核且最终审计通过后，自动生成当前版本的错题报告。
- 生成失败时保留已确认的复核结果，并提供明确错误和只重试生成物的入口。

## 功能需求

- F1：系统应审计任务列表、新建任务、识别进度、题目复核、学生答卷和批改工作台中的全部按钮与按钮式链接，确保每个可见操作已接线到导航、本地状态变化或服务端请求。
- F2：会发起异步请求的操作应在执行期间显示忙碌状态并防止重复提交；成功后显示结果并刷新受影响的数据；失败后在当前操作区域显示可读错误且允许重试。
- F3：按钮因前置条件不足而不可用时，应提供可见说明或可访问提示，指出缺少文件、题目尚未全部确认、仍有孤立答案、学生答卷未就绪、仍有待复核项等具体原因。
- F4：教师确认或修改批改复核项后，界面应立即更新该题得分、复核项数量和运行阶段；如果仍有复核项，应自动定位或清楚展示剩余项。
- F5：最后一项复核解决且题目与整卷审计通过后，系统应自动进入生成阶段，依次生成批注试卷和错题报告，无需教师额外点击。
- F6：错题报告应属于本次最终结果版本，包含每道非满分题的题号、题型、得分/满分、真实错误位置裁剪、错误原因、知识点和简短订正建议；满分题不进入逐题错题列表。
- F7：生成完成后，界面应显示可用的“预览错题报告”和“下载错题报告”入口；预览与下载失败时显示错误，不得静默无响应。
- F8：生成失败时运行应进入可恢复失败状态，展示失败原因，并允许仅重试批注/报告生成，不重新评分或丢失教师复核结果。
- F9：教师后续修改最终判定或错误位置时，旧报告应标记为过期；重新生成后的报告与最新结果修订一致。

## 非功能需求

- N1：主要操作在最新版 Chrome 和 Edge、1280×720 视口下可点击、可通过键盘访问，且不会被预览图层或固定操作栏遮挡。
- N2：按钮反馈不得只依赖颜色；忙碌、成功、失败和禁用原因应有文字或可访问名称。
- N3：同一生成请求重复触发不得创建重复的当前报告；重复点击不得重复提交同一复核结果。
- N4：修复不得改变既有评分规则、教师已经确认的得分、原始学生答卷文件或历史报告版本。
- N5：关键按钮闭环和“最后一项复核 → 报告可预览/下载”应有自动化测试，并保留真实浏览器验证记录。

## 不做的事

- 不重设计现有页面视觉风格或整体导航结构。
- 不改变题型评分算法、阈值或评分细则内容。
- 不在本次工作中新增班级汇总、跨学生统计或报告分享功能。
- 不自动补造缺失的错误位置；证据不足时继续要求教师处理并给出明确提示。

## 验收标准

- AC1：逐页执行主要按钮清单时，每个按钮都会产生导航、可见状态变化、成功提示或失败提示，不存在无反馈的可用按钮。（对应 F1、F2）
- AC2：对每类异步按钮模拟成功、服务端校验失败和网络失败，页面均正确解除忙碌状态、显示结果并允许继续操作。（对应 F2）
- AC3：所有不可用主按钮均能让教师知道具体前置条件；条件满足后无需刷新整页即可恢复可用。（对应 F3）
- AC4：解决一个非最后复核项后，得分与剩余数量更新，运行仍保持待复核；解决最后一项后，运行自动进入生成批注、生成报告并最终完成。（对应 F4、F5）
- AC5：最终完成状态下存在当前版本的错题报告，预览和下载均返回有效 PDF；报告逐题内容与最终评分及错误证据一致。（对应 F6、F7）
- AC6：模拟报告生成失败后，页面显示失败原因；点击继续处理只重跑生成物阶段，复核记录与最终分数保持不变，随后报告成功生成。（对应 F8）
- AC7：修改已完成运行的最终判定或错误位置后，旧报告不能作为当前结果下载；重新生成文件使用新的结果修订。（对应 F9）
- AC8：Chrome 和 Edge 在 1280×720 下可仅用鼠标或键盘完成“进入批改工作台 → 处理全部复核 → 预览错题报告 → 下载错题报告”的完整流程。（对应 N1、N2、N5）
- AC9：重复点击或重复请求不会产生重复复核提交、重复当前报告或分数二次变化。（对应 N3）
- AC10：现有前后端测试继续通过，原始答卷文件摘要、历史运行和评分规则均无变化。（对应 N4）
